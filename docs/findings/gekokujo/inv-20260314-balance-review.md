## 1. 各キャラの90秒間 石高シミュレーション

### 前提条件（コードから抽出した実数値）

| パラメータ | 農民 | 足軽 | 商人 |
|---|---|---|---|
| attack | 3 | 6 | 2 |
| speed | 2.8 | 3.5 | 3.2 |
| followerBonus | 0.015 | 0.01 | 0.005 |
| recruitRange | 65 | 55 | 0（勧誘不可） |
| recruitTime | 即時 | 400ms | N/A |
| chargeMultiplier | 0.8 | 1.0 | 0.5 |
| 敵撃破スコア加算 | +2石高 | +5石高 | +1石高 |

**敵データ**:
- 野盗: HP 20, score 10
- 足軽隊: HP 35, score 25
- 侍: HP 55, score 50
- 武将: HP 80, score 80

**スコア計算式**: `finalScore = rawScore * (1 + 仲間数 * followerBonus) * rankBonus`

### 商人（shonin）

**戦闘DPS**:
- 単発弾: damage `floor(attackPower * 0.5)` = 1（attack 2 * 0.5 = 1）、速度4（遅い）、CD 0.25秒
- 実効DPS: 4（当てにくい遅い弾で1ダメージ）
- 傭兵の攻撃判定: 農民と同じロジックだが、line 1672-1673で**農民限定**
- **傭兵に攻撃力なし**

**経済サイクル**:
- 村: +2石高/秒、城下町: +5石高/秒、その他: 0
- 傭兵雇用: 石高10で自動雇用、CD 2秒
- 維持費: 0.2石高/秒/人
- 敵撃破: +1石高（ただしDPS 4で野盗HP 20 = 5秒かかる）

**傭兵の最大維持数の計算**:

城下町滞在時（収入5/秒）:
- 維持費 = 傭兵数 * 0.2/秒

- ただし雇用に10石高/人、CD 2秒 → 90秒で最大45人雇用可能（石高あれば）
- 実際: 初期蓄積が必要。最初の10石高に2秒（城下町）、以降2秒ごとに1人

村滞在時（収入2/秒）:
- 収支均衡: 2 = n * 0.2 → **n = 10人**

## 2. バランスの問題点

### スコア比較サマリー

| レベル | 農民 | 足軽 | 商人 |
|---|---|---|---|
| 初心者 | 469 | 840 | 92 |
| 中級者 | 1,486 | 1,882 | 330 |
| 上級者 | 3,153 | 3,403 | 278 |

### 問題1: 商人が圧倒的に弱い（致命的）

**商人の上級者スコア(278)が農民の初心者スコア(469)を下回る。**

原因:
1. **傭兵に攻撃力がない**: line 1672-1673で仲間の攻撃判定は`farmer`限定。商人の傭兵は見た目だけで戦闘力ゼロ。
2. **プレイヤー攻撃力が壊滅的**: `damage = floor(2 * 0.5) = 1`。野盗(HP 20)を倒すのに5秒、侍(HP 55)に至っては14秒。
3. **地形収入だけでは勝てない**: 城下町+5/秒でも90秒で最大450石高。維持費を引くと実質200前後。
4. **スコア倍率が低い**: followerBonus 0.005は農民の1/3。

### 問題2: 農民と足軽のバランスは概ね良好

- 足軽は瞬間火力で勝るが、仲間の離脱があるためスケーリングが頭打ち
- 農民は序盤弱いが、仲間蓄積で後半爆発する正しいカーブ
- 上級者帯ではほぼ同等（足軽3,403 vs 農民3,153）

### 問題3: 足軽が初心者に優しすぎる

- 初心者帯で足軽840 vs 農民469 → 足軽が初手で選ばれ続ける「安定ピック」になる
- 農民は仲間を集めるまでの「弱い時間帯」が長く、初心者には辛い

## 3. 商人の経済バランス詳細分析

### 収入と維持費のバランス

```
城下町(+5/s)での傭兵維持可能数:
  5 / 0.2 = 25人（理論上限）

村(+2/s)での傭兵維持可能数:
  2 / 0.2 = 10人

雇用コスト: 10石高/人、CD 2秒
→ 城下町で10秒ごとに2石高余剰 → 5秒で10石高 → 2秒CDで1人雇用
→ 実際: 最初の雇用まで2秒、以降2秒ごとに1人
→ 25人雇うのに最低50秒
```

### 根本的な問題

**傭兵が戦わない**ため、傭兵を増やすインセンティブがfollowerBonus(x0.005)とfollowerMultによるスコア倍率のみ。25人の傭兵でもスコア倍率は`1 + 25 * 0.005 = 1.125`（たった12.5%増）。

石高を稼いで傭兵に変換しても、その傭兵が何もしない。**コストセンターを量産しているだけ**。

## 4. 一揆のバランス分析

### 仕組み（line 2275-2312）
- コスト: 仲間1人消費
- ダメージ: `paradeLen * 8`（消費前の仲間数で計算）
- 対象: 画面上の全敵
- CD: 20秒

### ダメージテーブル

| 仲間数 | 一揆ダメージ | 一撃で倒せる敵 |
|---|---|---|
| 5 | 40 | 野盗(HP20), 足軽隊(HP35) |
| 10 | 80 | 野盗, 足軽隊, 侍(HP55), 武将(HP80) |
| 15 | 120 | 全敵種 |
| 20 | 160 | 全敵種（城下町の1.5倍HP侍=82.5も） |

### 評価

- **仲間5-10人の一揆は妥当**: 野盗〜侍を一掃できるが、武将には届かない
- **仲間15人以上は過剰**: 全敵種を一撃。20人で160ダメージは武将も即死
- **CDが20秒は長いが、90秒ゲームなので最大4回使用可能**
- **コスト（1人消費）が軽すぎる**: 20人中1人消費で全画面一掃は低リスク高リターン

### バランス懸念

一揆自体は「農民の勝ち筋」として重要だが、**仲間20人で160ダメージ+全画面対象は強すぎる**。
特に城下町の強化敵（HP 1.5倍）すら一撃で、ゲーム後半のテンションが下がる。

### 調整案

| 案 | 内容 | 効果 |
|---|---|---|
| A. ダメージ上限 | `min(paradeLen * 8, 100)` | 武将は一撃で倒せない |
| B. コスト増 | 仲間の20%消費（最低1人） | 大群維持のリスク増 |
| C. 範囲制限 | 全画面 → プレイヤー中心半径200px | 位置取りが重要に |
| **推奨: B+C** | 20%消費 + 範囲制限 | 戦略性UP、パワーは維持 |

## 5. 足軽の離脱タイマー分析

### 仕組み（line 1610-1668）
- 加入時に`loyaltyTimer = 10 + random() * 20`（10〜30秒）を設定
- 毎フレーム減算、0になるとNPCに戻る（再勧誘可能）
- 離脱5秒前から点滅警告

### 定常状態の仲間数シミュレーション

```
平均滞在時間: 20秒
勧誘所要時間: 400ms + 接近時間 ≒ 2秒
民間人スポーン: 4秒ごとに1人（上限15）

→ 定常状態: 毎20秒で1人離脱
→ 毎2-4秒で1人補充可能（民間人がいれば）
→ 定常: 6-8人程度が現実的な上限
```

### 評価

- 10秒（最短）は短すぎる。勧誘直後に離脱するとフラストレーション大
- 30秒（最長）なら90秒ゲームの1/3を共に戦える → 体感は良い
- ランダム幅が大きい（10-30秒）ため、運要素が強い

### 調整案

| 現行 | 提案 | 理由 |
|---|---|---|
| 10-30秒 | **15-25秒** | 最短10秒の即離脱ストレスを軽減しつつ、回転率は維持 |

## 6. 下克上チャレンジ分析

### 城主のスペック（line 2496-2512）

```javascript
var rIdx = Math.min(ScoreManager.rankIndex + 2, RANKS.length - 1);
var hpReduction = ParadeController.getLength() * 3;
var bossHp = Math.max(30, 60 + rIdx * 40 - hpReduction);
// attack: 8 + rIdx * 4
// speed: 2.5
```

### ランク別城主スペック

| プレイヤーランク | rIdx計算 | bossHp（仲間0） | bossHp（仲間10） | boss attack |
|---|---|---|---|---|
| 農民(0) | min(2,5)=2 | 140 | 110 | 16 |
| 足軽(1) | min(3,5)=3 | 180 | 150 | 20 |
| 侍(2) | min(4,5)=4 | 220 | 190 | 24 |
| 武将(3) | min(5,5)=5 | 260 | 230 | 28 |
| 大名(4) | min(6,5)=5 | 260 | 230 | 28 |
| 天下人(5) | min(7,5)=5 | 260 | 230 | 28 |

**制限時間: 15秒**
**城主speed: 2.5（プレイヤーより遅い or 同程度）**
**城主攻撃: 1.0秒CD**

### 各キャラの攻略可能性

#### 農民（中級者、仲間14人、侍ランク）

```
必要DPS: 190 HP / 15秒 = 12.7 DPS
プレイヤーDPS: attack 3 + followerBonus(14*0.015*3*10=6.3) → 9.3 → 37.2 DPS（CD 0.25秒）
仲間DPS: 14人 * 3/秒 = 42 DPS
合計: 79 DPS → 190 / 79 = 2.4秒で撃破
一揆: 14*8=112ダメージ → 残78HP → 1秒で撃破
```
**結論: 余裕で攻略可能**

#### 足軽（中級者、仲間5人、武将ランク）

```
必要DPS: 230 HP / 15秒 = 15.3 DPS
プレイヤーDPS: attack 6 + followerBonus(5*0.01*6*10=3) → 9 * 5発 → 最大180 DPS
仲間: 攻撃力なし
実効（2-3発ヒット）: 54-81 DPS → 230 / 67 = 3.4秒
```
**結論: 攻略可能。ただし被ダメージ20-28/秒は痛い（15秒で最大420ダメージ。HP100では持たない → 回避必須）**

#### 商人（中級者、傭兵15人、侍ランク）

```
必要DPS: 190 HP / 15秒 = 12.7 DPS
プレイヤーDPS: damage floor(2*0.5)=1、CD 0.25秒 → 4 DPS
傭兵DPS: 0（攻撃判定なし）
合計: 4 DPS → 190 / 4 = 47.5秒 → **15秒では絶対に倒せない**
```
**結論: 攻略不可能。商人は下克上チャレンジをクリアする手段がない。**

## 7. 辻斬りQTE分析

### 仕組み（line 2057-2193）
- 毎秒、野盗 or 侍がいれば10%（地形補正あり）で発動
- カットイン0.8秒 → 入力受付1.0秒（SPACE押下）
- 成功: 攻撃者即死 + rawScore 100
- **失敗: プレイヤー即死（HP=0、ゲームオーバー）**

### 発動確率

```
地形補正:
  村・城下町: x1.0
  山: x0.2
  草原: x0.1
  橋・川・城: x0

1秒あたり: max 10% * 地形補正 * 敵数（野盗+侍のみ）
90秒間で村に30秒滞在 → 期待発動回数: 30 * 0.1 * (平均2体) = 6回
```

### 評価

- **失敗=即死は厳しい**: 90秒中に6回発動すると仮定すると、1回でも見逃せば即終了
- **入力受付1.0秒は短くはないが**: カットイン0.8秒の認知時間を含めると、初見では何が起きたか分からないまま死ぬ
- **ゲーム中断が頻繁すぎる**: 村で稼ぐ商人は特に辻斬りが多発 → 経済活動を妨害される上に即死リスク

### 調整案

| 現行 | 提案 | 理由 |
|---|---|---|
| 失敗=即死 | **失敗=HP50%ダメージ+ノックバック** | 緊張感は維持しつつ、理不尽さを軽減 |
| 入力受付1.0秒 | 1.0秒は適正 | カットイン時間で覚悟できる |
| 発動率10%/秒 | **5%/秒** | 90秒ゲームで3回程度が適正 |

## 8. 総合評価と調整提案

### 優先度: 高（致命的問題）

#### 商人の全面的なバフ

1. **傭兵に攻撃力を付与する**（農民と同じ仕組み: 30px範囲、3ダメージ、1秒CD）
   - line 1672-1673の`farmer`チェックを`farmer || shonin`に変更
   - これだけで傭兵15人 = 45 DPS追加。下克上チャレンジも攻略可能に

2. **プレイヤー攻撃のdamage半減を撤廃**
   - line 1922: `Math.floor(damage * 0.5)` → `damage`
   - attack 2でも4 DPS → 8 DPSに改善

3. **敵撃破石高を+1→+3に**
   - line 2396: `gameState.koku += 1` → `gameState.koku += 3`
   - 傭兵が戦えるようになれば、撃破→石高→追加雇用のフィードバックループが回る

### 優先度: 中

4. **一揆の範囲制限**: 全画面 → 半径200px + コスト仲間20%消費
5. **足軽の離脱タイマー**: 10-30秒 → 15-25秒
6. **辻斬り失敗**: 即死 → HP50%ダメージ + 発動率5%/秒

### 優先度: 低

7. **農民のrecruitTime**: CHAR_DEFS上は500msだが実装は即時（line 1542-1545）。定義値を0に修正しておくべき（混乱防止）

### 11-5. 経済システム（石高）

#### 石高の二重性

石高は「スコア（finalScore）」と「リソース（koku）」の二重の意味を持つ。

- **スコアとしての石高**: `rawScore`に加算され、`followerMult * rankBonus`でfinalScoreになる（line 2630-2634）
- **リソースとしての石高（koku）**: 商人の傭兵雇用に使用。全キャラ共通で`ShoninSystem.addKokuForKill`で加算される（line 2421-2430）が、**商人以外ではkokuは使わない**（line 2366: `if (selectedChar !== "shonin") return`）

#### 各キャラの石高稼ぎ方

| キャラ | 主な石高源 | 副次的石高源 | koku用途 |
|---|---|---|---|
| 足軽 | 敵撃破（DPS最高） | 威圧降伏 | なし（+5/killだが未使用） |
| 農民 | 敵撃破+一揆 | 仲間攻撃判定、攻撃時20%民衆スポーン | なし（+2/killだが未使用） |
| 商人 | 地形収入（村+2/s、城下町+5/s） | 傭兵の敵撃破、辻斬りカウンター | 傭兵雇用（10/人）、維持費（0.2/s/人） |

#### 商人の収入/支出サイクルの面白さ

**調整後の商人経済は大幅に改善されている**。

改善点:
1. 傭兵が戦える（3DPS/人）→ 敵撃破→ rawScore増加 + koku+3のフィードバックループ
2. 攻撃半減撤廃 → プレイヤー自身も最低限の戦闘力を持つ
3. 敵撃破+3koku → 傭兵が稼いだkokuで新たな傭兵を雇える正のスパイラル

残存する問題:
- **傭兵が自動雇用**（line 2412）のため、プレイヤーの経済判断が「城下町に行く」だけに帰結する
- 「傭兵を雇わない」という選択肢がない（koku >= 10で強制雇用）
- 維持費で石高が減っていく感覚がスコアアタックとしてはネガティブ

**修正提案（優先度: 低）**: 傭兵の自動雇用を手動（Eキー等）にすることで、「貯金してスコアを伸ばす」vs「傭兵を増やして戦力を増す」の判断を追加できる。ただし操作の複雑化とのトレードオフ。

### 11-6. 見落としている問題

#### 問題A: 一揆のボスへの無条件適用（重要度: 高）

前述の通り、一揆のダメージはボスに対して距離チェックなし（line 2334-2338）。通常敵には200px範囲制限があるのにボスにはない。

**影響**: 農民は下克上チャレンジ開始直後に一揆を使えば、ボスの位置に関係なく大ダメージを与えられる。仲間20人なら160ダメージでボスHP175のうちほとんどを削れる。

**修正案**: ボスにも同じ200px範囲チェックを追加。

```javascript
// line 2334-2338 を以下に変更
if (GekokujoSystem.boss) {
  var bdx = GekokujoSystem.boss.x - PlayerController.x;
  var bdy = GekokujoSystem.boss.y - PlayerController.y;
  if (Math.sqrt(bdx * bdx + bdy * bdy) <= ikkiRadius) {
    GekokujoSystem.boss.hp -= damageAmount;
    // ...
  }
}
```

#### 問題B: 商人の辻斬りカウンターが強すぎる経済効果（重要度: 中）

辻斬りカウンター成功で+100 rawScore（line 2200）+ koku+100（line 2201のaddKokuForKill→line 2428で+3...）

**ここに計算ミスがある**: `addKokuForKill(100)`は`scoreValue`として100を受け取るが、商人の場合`gameState.koku += 3`（固定値、line 2428）。つまり辻斬りカウンターでもkokuは+3しか入らない。scoreValueの大きさに関係なく固定。

これは**意図的かバグか不明**。野盗を倒しても侍を倒しても辻斬りカウンターしても一律+3koku。もしscoreValue連動にすると辻斬りカウンター1回で100kokuが入り、傭兵10人が即座に雇える。現状の固定+3は妥当。

#### 問題C: 足軽の仲間が威圧にしか寄与しない（重要度: 低）

足軽の仲間は攻撃判定なし（line 1672-1673: farmerとshoninのみ）、離脱あり（15-25秒）。仲間の役割は:
- 威圧（気骨値比較）
- followerBonus（attack * 0.01 * paradeLen * 10）
- 行列突撃（chargeMultiplier 1.0）
- 下克上のbossHP減少（-3/人）

これは設計意図通り（足軽は自力で戦うキャラ）なので問題ではないが、**仲間を集めるモチベーションが他キャラより薄い**。仲間6人で維持しても威圧で野盗が降伏する程度（気骨3 < 6）。足軽隊の降伏には11人必要だが、離脱で維持が困難。

#### 問題D: 初心者が5秒で投げ出すリスク（重要度: 高）

**商人で開始した初心者の体験**:
1. フィールドに出る
2. 敵が近づいてくる
3. 攻撃する → 弾が遅い（弾速4, line 1922）、当たっても1ダメージ（attack 2のfollowerBonus 0）
4. 敵に殴られる → HP減少
5. 仲間を勧誘できない（recruitRange: 0）
6. 石高0、傭兵0、何もできない
7. 「このキャラ弱すぎ。もうやらない」

**対策案**: キャラ選択画面（line 111-159）に難易度表示を追加。商人に「上級者向け」「序盤は弱いが中盤から逆転」等の警告を明示する。現状は「経済型 / 戦略向け」（line 146）のみで、弱さへの心理的準備が不十分。

#### 問題E: ゲームを壊すコンボ — 農民の無限スケーリング（重要度: 中）

農民の仲間は**不死で離脱なし**。攻撃時20%で民衆追加スポーン（line 1930）。仲間の攻撃判定で敵を倒す→敵再スポーン→倒す→のループ中に民衆もスポーン。

理論的には仲間数に上限がない（民間人の上限20はスポーンの上限、加入後は制限なし）。仲間30人以上になると:
- followerBonus: 30 * 0.015 * 3 * 10 = 13.5 → attack 16.5
- 仲間DPS: 30 * 3 = 90
- 一揆: 30 * 8 = 240（全敵即死）
- 一揆コスト: 6人消費 → 24人残り → すぐ回復

**現実的には90秒では30人到達は困難**（民間人スポーン4秒/人、上限15体ストック: line 1513-1515）。しかし上級者が民衆密集地帯を巡回すれば20-25人は可能で、この時点で一揆が過剰火力になる。

**現状のバランスは許容範囲内**だが、民衆スポーン上限（20体: line 1455）が安全弁として機能している。

#### 問題F: 行列突撃（右クリック）のキャラ間バランス（重要度: 低）

chargeMultiplier: 足軽1.0 > 農民0.8 > 商人0.5

行列突撃は6秒CD（line 231付近）で全員が使えるが、**商人の0.5倍は弱すぎて使う意味がほぼない**。傭兵が攻撃判定を持つようになった今、突撃でばらけると逆にDPSが下がる（再集結中は攻撃判定の密度が落ちる）。

商人の行列突撃は「罠操作」（使うと弱くなる）になっている可能性がある。

### 11-7. 総合所見

#### バランスの全体評価

| 項目 | 評価 | 理由 |
|---|---|---|
| 3キャラの差別化 | 良好 | 足軽=火力、農民=行列+一揆、商人=経済。明確に異なる体験 |
| 90秒の体験密度 | 良好 | 3ウェーブ制（line 1332-1338）で30秒ごとに緊張感が上がる |
| リプレイ性 | 良好 | ランダムマップ + 3キャラ + 下克上判断 |
| 初心者の導入 | やや問題 | 商人の序盤が厳しすぎる。足軽はOK、農民は仲間集めで手持ちぶさたにならない |
| 上級者の天井 | 良好 | 農民の一揆タイミング、足軽のエイム精度、商人のルート最適化 |
| ゲームブレイク | 軽微 | 一揆のボス無条件適用のみ要修正。無限スケーリングは90秒の時間制限が安全弁 |

#### 修正優先度まとめ

| 優先度 | 項目 | 修正内容 |
|---|---|---|
| **高** | 一揆のボス距離チェック | ボスにも200px範囲制限を適用（line 2334-2338） |
| **高** | 辻斬りQTE倍率の設計乖離 | 足軽x1.3→x0.55、農民x0.8→x1.0に修正（line 2092-2093） |
| **中** | 商人の城下町辻斬り倍率 | 2.0→1.5に下げ（line 2129） |
| **低** | 商人の序盤体験 | キャラ選択画面に難易度警告を追加 |
| **低** | 商人の行列突撃 | chargeMultiplier 0.5の意図を再検討（使うと弱くなる問題） |

#### 結論

セクション10の調整が全て実装されたことで、**商人の致命的な弱さは解消**されている。3キャラの体験差は設計意図通りに機能しており、90秒の体験曲線にも致命的な穴はない。

残る問題は主に2点:
1. **一揆のボスへの無条件適用**（農民の下克上が簡単すぎる）
2. **辻斬りQTE倍率が設計書と逆**（足軽が簡単すぎる）

これらは数値の修正で対応可能であり、ゲームの根幹設計には影響しない。
