# 下克上オンライン — ゲーム設計書（合体版: 案1+5）

## 1. ゲームコンセプト

**「和風フィールドを駆け回り、民衆の大行列を率いて成り上がれ。90秒で農民から天下人へ。」**

見下ろしアリーナアクション（案1）の操作感に、ピクミン式パレード（案5）の「仲間が周囲を取り囲む快感」を融合。ランダム生成される広大な和風マップで、毎回異なる戦略判断が求められる。

## 2. ジャンル定義

**トップダウン・アーケードアクション（PvE・スコアアタック型）**

- 見下ろし視点のフィールドでマウスカーソルを照準として使うアクションゲーム
- 1プレイ90秒の固定時間制
- スコア＝「石高」で順位が決まるランキング制
- ブラウザ即プレイ（インストール・ログイン不要）
- **ランダムマップ生成**によるローグライク的リプレイ性

## 3. キャラ選択

ゲーム開始時に3つの「身分」から1つを選ぶ。それぞれ初期ステータスと固有能力が異なる。

> **注**: タイトル画面に描かれているキャラは3体。3種は農民・足軽・商人。

### 農民（ひゃくしょう）— テクニカル / 玄人向け ★

- **コンセプト**: 最弱ステータスだが「一揆」による大逆転が可能な超ハイリスク・ハイリターン型
- **攻撃力**: ★☆☆☆☆（attack: 3）
- **移動速度**: ★★☆☆☆（speed: 3.2）
- **攻撃特性**: 短射程・狭範囲（blast: 2）・ホーミングなし。弾速6、寿命28フレーム
- **勧誘**: 説得時間あり（recruitTime: 400ms）。勧誘範囲65px + 行列人数×5px
- **followerBonus**: 0.025（最高値。仲間を集めるのが大変な分リターンが大きい）
- **仲間の攻撃判定**: 各仲間の周囲30pxに攻撃判定。3ダメージ、1秒クールダウン
- **仲間は不死**: 敵に殺されない
- **一揆（Qキー）**: 仲間1人消費、全敵に仲間数×8ダメージ、15秒CD、最低1人必要、コスト10%消費
- **攻撃時ボーナス**: 攻撃ヒット時に30%の確率で民衆が新たにスポーン
- **scoreMultiplier**: 1.2（全ての石高獲得に乗算）
- **民衆ボーナス**: 集めた民衆1人につき全ステータス+2.5%
- **なぜテクニカルか**: 序盤が圧倒的に弱い。一揆のタイミング判断が勝敗を分ける。上手い人が使うと爆発力は全キャラ中最大
- **初心者では最弱だが、上級者が使いこなすと全キャラ中圧倒的最強のスコアを出せる**

### 足軽（あしがる）— バランス型 / 入門向け

- **コンセプト**: バランス型。クセがなく扱いやすい
- **攻撃力**: ★★★☆☆（attack: 7）
- **移動速度**: ★★★☆☆（speed: 3.0）
- **攻撃特性**: 短射程・広範囲。前方扇状に5発同時発射（角度差0.25rad、弾速8、寿命24フレーム、blast: 10）
- **勧誘**: 説得時間あり（recruitTime: 200ms、最も短い。初心者向け）。勧誘範囲55px + 行列人数×5px
- **followerBonus**: 0.008
- **scoreMultiplier**: 1.0
- **仲間は不死**: 敵に殺されない
- **仲間の離脱**: 毎秒 `0.5% × パレード人数` の確率で1人離脱（人数スケール型）
  - 例: 10人 → 5%/秒、20人 → 10%/秒、30人 → 15%/秒
  - 離脱した民衆は現在地付近に再スポーン（再勧誘可能）
- **パレード攻撃判定**: あり（各仲間の周囲30pxに攻撃判定。2ダメージ、1秒クールダウン。他キャラより低い）
- **民衆ボーナス**: 集めた民衆1人につき攻撃力+0.8%
- **鼓舞（Qキー）**: 5秒間攻撃速度ブースト（攻撃CD 1.0秒→0.3秒）。15秒CD、コストなし
- **本懐ボーナス**: 下克上達成時（ボス撃破）に **3000 ± 25%（2250〜3750石）** が加算される。アナウンス: 「本懐成就! +XXXX石!」（緑バー）。武功ボーナスとは別枠
- **初心者帯で最強。上級者帯では農民・商人に追い越される**

### 商人（あきんど）— 経済型 / 戦略向け ★

- **コンセプト**: 金で仲間を即座に集められるが、維持費がかかる。とっつきやすい戦略型
- **攻撃力**: ★☆☆☆☆（attack: 2）
- **移動速度**: ★★★☆☆（speed: 3.6）
- **攻撃特性**: 短射程・単発・低速（弾速4、寿命15フレーム、blast: 4）
- **勧誘**: 即時リクルート（触れるだけで仲間に）。ただし1人につき石高120消費。勧誘範囲55px（足軽と同等）+ 行列人数×5px
- **初期石高**: 2500（バッファでスタート）
- **仲間の攻撃判定**: 各仲間の周囲30pxに攻撃判定。3ダメージ、1秒クールダウン
- **followerBonus**: 0.007
- **scoreMultiplier**: 1.2（全ての石高獲得に乗算）
- **地形収入**: 草原にいると+1石高/秒、村にいると+3石高/秒、城下町にいると+5石高/秒
- **仲間の維持費**: 0.3石高/秒/人
- **自動雇用**: 石高15消費で民衆を自動雇用（3秒クールダウン）
- **仲間の離脱**: 「金の切れ目が縁の切れ目」——2つのルールで離脱が発生する
  - **石高ゼロで離脱**: 石高が0を下回ると仲間が1人ずつ離脱（1秒CDで順次）
  - **確率的離脱**: 石高に関わらず常時 **8%±4%/秒** の確率で1人が離脱する
  - 離脱した傭兵はランダムな村/城下町付近にスポーン（すぐ再勧誘はできない）
- **買収（Qキー）**: 5秒間「買収オーラ」を展開（半径150px）。範囲内の敵が味方に転換する。石高50消費、15秒CD

### キャラバランス設計（パワーカーブ）

| レベル | 農民 | 足軽 | 商人 |
|--------|------|------|------|
| 初心者 | 最弱（200pt） | **最強**（860pt） | 中間（461pt） |
| 中級者 | 最弱（1,259pt） | 同等（1,456pt） | 同等（1,550pt） |
| 上級者 | **圧倒的最強**（4,534pt） | 最弱（2,772pt） | 中間（3,231pt） |

- 足軽: スキルカーブが緩やか。誰が使っても安定したスコア
- 商人: 中間のスキルカーブ。序盤のとっつきやすさと中盤以降の戦略性

## 4. 1プレイの流れ（90秒）

```
[0秒] キャラ選択画面
  農民 / 足軽 / 商人 から選択
  ↓
[START] ランダムマップ生成 → フィールドに出現（90秒カウントダウン開始）
  ↓
[0〜90秒] メインフェーズ ——————————————————————
  │
  ├─ 移動: WASDキーで上下左右に移動
  ├─ 照準: マウスカーソルで攻撃方向を指定
  ├─ 攻撃: 左クリックでカーソル方向に攻撃
  ├─ 行列突撃: 右クリック（6秒クールダウン）
  │
  ├─ 敵NPCを倒す → 石高（スコア）獲得 + 身分上昇
  ├─ 民衆に近づく → 仲間に加わり行列の後ろに連なる
  ├─ 行列が長いほどキャラ強化 + 弱敵が自動降伏（威圧）
  │
  ├─ [ランダム] 辻斬りQTE（村・城下町で発生。SPACEで回避、失敗＝即死、成功＝カウンター）
  ├─ [全キャラ] 固有能力Q（農民: 一揆 / 足軽: 鼓舞 / 商人: 買収）
  ├─ [任意] 下克上チャレンジ（城門に攻め込む。断っても5秒後に再挑戦可能）
  │
  ↓
[85秒] 終了5秒前カウントダウン（画面中央に5→4→3→2→1を大きく表示）
  ↓
[90秒 or ゲームオーバー] ゲームエンド
  │
  ├─ 通常終了 → 「お主は ○○位」（石高ベースのランキング表示）
  ├─ 下克上成功 → 「下克上成功!! お主は ○○位」
  └─ 下克上失敗 → ドクロ画面（ゲームオーバー）
```

## 5. コアメカニクス

### 5-1. 操作方法

| 入力 | アクション |
|------|-----------|
| WASD | キャラの移動（上下左右） |
| マウス移動 | 照準カーソルの操作（攻撃方向の指定） |
| 左クリック | カーソル方向に通常攻撃（0.25秒クールダウン） |
| 右クリック | 行列突撃（6秒クールダウン） |
| Qキー | 固有能力（キャラ別: 農民=一揆、足軽=鼓舞、商人=買収） |
| スペースキー | 辻斬りQTE回避専用（通常時の回避アクションは無し） |

**操作の棲み分け**: 左クリック攻撃 + WASD移動だけで基本プレイが完結する。右クリックの行列突撃は「知ってると強い」上級テクニック。

### 5-2. フィールド構造（ランダムマップ生成）

- トップダウン（見下ろし）視点の和風マップ
- **タイルセット: Kenney Roguelike RPG Pack** を使用（スプライト画像でキャラ・建物を描画）
- **フィールドサイズ: 2400×1800px（画面9枚分 = 3×3グリッド）**
- **カメラ: プレイヤー追従のシームレススクロール**（デッドゾーン付きで酔い防止）

#### ランダムマップ生成ルール

```
[マップ生成アルゴリズム]

1. フィールドを3×3の9ブロック（各800×600px）に分割

2. 城配置: 外周8ブロックからランダム1箇所
3. プレイヤー初期位置: 城から最低2ブロック離れたブロック

4. 川: 城とプレイヤーの間を縦方向に流れる形で1本配置
   - 川のX座標は城とプレイヤーの列中心
   - 川幅: 60〜150pxランダム
   - 橋は横向きで2箇所:
     - 近い橋: 狭い（幅70px。辻斬りリスク高、行列が一列に詰まる）
     - 遠い橋: 広い（幅120px。安全だが遠回り）
   - 川は通行不可（速度0.3倍）。橋でのみ渡れる

5. 地形は平地・草原・村・城下町のみ（山は削除済み）
   - 草原: 2-3箇所。プレイヤー初期位置の近く（民衆密集地帯）
   - 城下町: 城の隣接ブロック（強敵密集、城のガード）
   - 村: 0-2箇所（民衆リスポーン地帯、安全）
```

#### UI: ミニマップ + 城方向矢印

- **右上にミニマップ常時表示**（128×96px）
  - 城 = 赤アイコン
  - 自分 = 白点
  - 民衆密集地 = 緑点
  - 橋 = 茶色の線
- **画面端に城方向の矢印**を常時表示（コンパス的UI）
- 城の位置は最初からミニマップで見える（「探す」時間をゼロにする）

### 5-3. 敵NPC

身分の階層に対応した敵が出現する。ウェーブ的段階強化（30秒ごと）:

| 敵 | HP | 攻撃力 | 速度 | 石高 | 気骨値 | 威圧で降伏する行列長 |
|----|-----|-------|------|------|--------|-------------------|
| 野盗 | 20 | 3 | 1.5 | 10 | 3 | 4人以上 |
| 足軽隊 | 35 | 5 | 1.8 | 25 | 10 | 11人以上 |
| 侍 | 55 | 8 | 2.0 | 50 | 999 | 降伏しない |
| 武将 | 80 | 12 | 2.2 | 80 | 999 | 降伏しない |
| 城主 | 下克上 | — | — | 特大 | — | — |

- 城下町にいる敵はHP1.5倍
- スプライトは全敵共通で野武士（nobushi）画像を使用

**ウェーブ演出**: 30秒ごとに太鼓の音で「次の波が来る」と告知。90秒に3幕のドラマを作る。

**身分上昇**: 累計石高に応じてプレイヤーの身分が自動で上がる:

| 身分 | 必要石高 | ボーナス倍率 |
|------|---------|------------|
| 農民 | 0 | 1.0 |
| 足軽 | 50 | 1.2 |
| 侍 | 150 | 1.5 |
| 武将 | 350 | 2.0 |
| 大名 | 700 | 2.5 |
| 天下人 | 1200 | 3.0 |

### 5-4. 民衆と行列システム（案5融合の核心）

#### 行列の基本挙動（ピクミン式パレード）

- 仲間にした民衆はプレイヤーの周囲を**ピクミン式に周回（オービット）**する
- 各民衆は半径40〜80pxの範囲でプレイヤーを中心に配置され、sin波によるウォブル（揺れ）で自然な動きを演出
- 移動はlerp 0.1で滑らかに追従（急な方向転換でも自然に付いてくる）
- **全仲間が射程内の敵に自動攻撃**（ピクミン式戦闘）
- **下克上チャレンジ中、仲間はボスにも攻撃を行う**
- 仲間が増えるほど周回の密度が上がり、視覚的な圧力と火力が増す

#### 仲間の挙動（キャラ別差異）

| 特性 | 農民 | 足軽 | 商人 |
|------|------|------|------|
| 仲間の獲得方法 | 説得時間あり（400ms） | 説得時間あり（200ms、最短） | 即時（石高120消費） |
| 仲間の不死 | ○ | ○ | ○ |
| 仲間の離脱 | なし | 毎秒 `0.5% × 人数` の確率で1人離脱（人数スケール型） | 石高ゼロで離脱 + 8%±4%/秒の確率的離脱が常時発生 |
| 離脱時の挙動 | — | 現在地付近に再スポーン（再勧誘可能） | ランダムな村/城下町付近にスポーン（すぐ再勧誘不可） |
| 離脱警告 | — | なし | 「石高不足!」アナウンス |
| 攻撃判定 | あり（30px、3dmg、1秒CD） | あり（30px、**2dmg**、1秒CD） | あり（30px、3dmg、1秒CD） |

#### 威圧システム（案5由来）

```
威圧値 = 行列の人数

判定: 行列の人数 > 敵の「気骨値」 → 敵が白旗降伏（戦闘なしで石高自動獲得）
  - 野盗: 気骨値 3（行列4人以上で降伏）
  - 足軽隊: 気骨値 10（行列11人以上で降伏）
  - 侍: 降伏しない（気骨値 999）
  - 武将: 降伏しない（気骨値 999）
```

**降伏演出**: 弱敵が行列を見て白旗を掲げ、ひれ伏す → 自動で石高獲得。長い行列で歩くだけでスコアが入る快感。

#### 行列突撃（右クリック）

- 行列全体が前方に突進し、接触した敵にダメージ
- 突撃後、行列がばらける → 再集結に数秒かかる（その間無防備）
- 6秒クールダウン
- キャラごとに突撃速度・威力が異なる（chargeMultiplier参照）

#### パレード攻撃判定（全キャラ共通）

- 全キャラのパレード仲間には**攻撃判定**がある（各仲間の周囲30pxに攻撃判定円）
- 農民・商人: 接触すると3ダメージ（1秒クールダウン）
- 足軽: 接触すると**2ダメージ**（1秒クールダウン。他キャラより低い）
- 仲間の数＝火力
- **仲間は不死**（敵に殺されない）

#### 勧誘範囲の動的拡大

- **団体サイズが大きいほど勧誘範囲が広がる**: `effectiveRange = baseRange + paradeLength × 5px`
- 大行列の「勢い」が勧誘力に反映される設計

### 5-5. スコア（石高）計算

```
最終石高 = (敵撃破石高 + 威圧降伏石高 + イベントボーナス) × 民衆係数 × 身分ボーナス × scoreMultiplier

民衆係数 = 1.0 + (行列の人数 × キャラ固有倍率)
身分ボーナス = 現在の身分に応じた倍率（農民1.0 → 天下人3.0）
scoreMultiplier = キャラごとに設定された全石高獲得への乗数（足軽: 1.0、商人: 1.2、農民: 1.2）
```

**scoreMultiplier**: 全ての石高獲得（敵撃破・威圧降伏・イベントボーナス）にキャラ固有の倍率が乗算される。農民・商人は足軽より20%多くスコアが入る設計。

**敵撃破時の石高加算（キャラ別）**:
- 農民: +2石高
- 足軽: +5石高（最も高い）
- 商人: +3石高

### 5-6. ランキング

- 石高を全プレイヤーの中で順位づけ → 「お主は ○○位」
- ランキングは永続（累積ハイスコアボード）
- ログイン不要: ニックネーム入力のみ（3〜8文字、和風推奨）

## 6. 下克上チャレンジの仕組み

### 発生条件
- ゲーム開始30〜50秒後に城門が出現
- 城門に近づくと「下克上を仕掛ける？」→ はい / いいえ の選択
- ミニマップで城の位置は最初からわかる。到達ルートの判断がゲーム性
- **断っても5秒後に城門が再出現**（何度でも挑戦可能）

### 挑戦内容
- 「はい」を選ぶと城主（ボスNPC）との1対1バトル
- **殿様は出現から20秒で撤退する**。20秒以内に倒せなかった場合は「殿様は去った...」で不戦終了（ゲームオーバーにならない）
- HUDのタイマーが「下克上」ラベルに切り替わり、残り秒数を表示
- **行列の人数が城主のHP減少に寄与**: 行列が長いほど城主のHPが低い

### 成功時
- 城主の石高を総取り + 身分が2段階ジャンプ
- 「下克上成功!!」の演出（集中線）→ 石高で順位確定 → ゲームエンド
- **武功ボーナス**: 15秒以内撃破で +2000石（アナウンス: 「武功! +2000石!」）
- **足軽限定・本懐ボーナス**: ボス撃破時に **3000 ± 25%（2250〜3750石）** を追加獲得。アナウンス: 「本懐成就! +XXXX石!」（緑バー）。武功ボーナスとは別枠で加算

### 失敗時
- **倒された場合**: 城主に倒される → 「下克上失敗.....」→ ドクロ画面 → ゲームオーバー（石高は記録されない）
- **時間切れの場合**: 20秒経過 → 「殿様は去った...」→ 不戦終了（ゲームオーバーにならない。断っても5秒後に再出現は維持）

### 戦略的ジレンマ
- 行列を長く育てて城に行く → 城主が弱い（行列HP減少）が、橋で辻斬りリスク
- 行列なしで速攻 → 城主が強い。民衆係数も低いのでスコアが伸びない
- 挑まない → 90秒フルに使って堅実にスコアを稼ぐ
- **20秒の時間圧力**: 殿様は20秒で撤退するため、火力が足りないと時間切れになる。一揆・鼓舞・買収の温存判断が重要
- **ルート判断**: 城が近い回は下克上を狙い、遠い回は堅実プレイ。マップ運もゲーム性

## 7. 辻斬りQTEの仕組み

### 発生
- 野盗または侍が一定確率で仕掛けてくる
- **毎秒2.5%×地形倍率で判定**（ベース発動率2.5%）
- **ボスレイド中（battleActive）は発生しない**
- 地形倍率はキャラ別に設定（下表参照）
- 橋の上・川の中・城内では発生しない（倍率0）
- **カットイン演出**が入る（画面が一瞬スローモーションになる）

#### 地形倍率テーブル（キャラ別）

| 地形 | 足軽 | 商人 | 農民 | 設計意図 |
|------|------|------|------|----------|
| 村 | 0.5 | 1.5 | 0.8 | 商人は村に長居するため遭遇多め |
| 城下町 | 0.6 | 2.0 | 0.8 | 商人の主戦場で最多 |
| 山 | 0.15 | 0.1 | 0.2 | 農民は山でも遭遇 |
| 草原・空き地 | 0.08 | 0.05 | 0.1 | 全体的に低い |
| 橋・川・城 | 0 | 0 | 0 | 発生しない |

### QTE回避
- カットイン（0.8秒）後にSPACEキーを押して回避
- **QTE入力猶予**: ベース1.8秒 × キャラ倍率 × ランダム(0.7〜1.3)
  - **足軽**: 倍率x1.3 → 実効1.64〜3.04秒（遭遇少ないが対処しやすい）
  - **商人**: 倍率x1.0 → 実効1.26〜2.34秒（標準）
  - **農民**: 倍率x0.8 → 実効1.01〜1.87秒（やや厳しい）
- **成功 → カウンター発動**: 敵を倒す + 100石高ボーナス獲得
- **失敗 → 即死**（ゲームオーバー）

### 戦略的意味
- 村・城下町は民衆が多く石高収入も高いが、辻斬りリスクも存在
- カウンター成功で+100石高は大きなスコアブースト（商人にとっては城下町での地形収入10秒分）
- 失敗すると即死。辻斬りは一発退場のハイリスクイベント
- キャラごとに遭遇頻度と対処難易度が異なり、プレイ体験に変化を生む

### 5-7. 終了カウントダウン演出

- 残り5秒（85秒経過時点）で画面中央に大きくカウントダウン表示（5→4→3→2→1）
- 墨文字スタイルで表示。ゲーム開始の3→2→1と対になる演出
- カウントダウン中もゲームは続行（操作可能）

## 8. 一揆の仕組み（農民専用・必殺技）

### 発動方法
- **農民使い限定**の必殺技
- **Qキー**で任意発動（ランダムイベントではなく、プレイヤーの判断で使う）
- **コスト**: パレードの仲間の**10%を消費**（最低1人。末尾から順に離脱）
- **制約**: 最低**1人**のパレード仲間が必要
- **クールダウン**: **15秒**

### 効果
- プレイヤー中心**半径200px**以内の全敵に `仲間の人数 × 8` ダメージ
- ボス（下克上チャレンジ中の城主）にも有効（※現実装ではボスに対して距離チェックなし）
- 例: 仲間10人 → 1人消費（10×0.1=1） → 半径200px内の全敵に `10 × 8 = 80` ダメージ

### 戦略的ジレンマ
- **早すぎると**: 仲間不足で城主に勝てない
- **遅すぎると**: 時間切れでスコアが伸びない
- **10%消費**: 仲間20人で一揆を撃つと2人を失う。大群維持のリスクと火力のトレードオフ
- **半径200px制限**: 位置取りが重要。敵を範囲内に集めてから発動する判断が必要
- 一揆のタイミング判断が農民プレイの最大の駆け引き

## 9. 鼓舞の仕組み（足軽専用・必殺技）

### 発動方法
- **足軽使い限定**の必殺技
- **Qキー**で任意発動（プレイヤーの判断で使う）
- **コスト**: なし（クールダウンのみ）
- **クールダウン**: **15秒**

### 効果
- **5秒間、仲間全員の攻撃速度が大幅ブースト**（攻撃CD 1.0秒→0.3秒）
- ピクミン式パレードの全仲間が高速で敵を攻撃し続ける
- プレイヤー自身の攻撃速度には影響しない

### 戦略的ジレンマ
- **敵の群れに突っ込んでQで火力集中**: 仲間が多いほど鼓舞の恩恵が大きい（DPS 3.3倍）
- **クールダウン管理**: 15秒CDなので下克上前に温存するか、道中の強敵処理に使うかの判断
- **仲間の数が火力に直結**: 仲間10人なら鼓舞中の総DPSは約100/秒（通常時30/秒）

## 10. 買収の仕組み（商人専用・必殺技）

### 発動方法
- **商人使い限定**の必殺技
- **Qキー**で任意発動（プレイヤーの判断で使う）
- **コスト**: **石高50消費**
- **クールダウン**: **15秒**

### 効果
- **5秒間「買収オーラ」を展開**（半径150px）
- オーラ範囲内に入った敵が**味方に転換**する（敵→仲間）
- 転換した元敵はパレードメンバーとして加わり、攻撃判定を持つ

### 戦略的ジレンマ
- **石高管理と発動タイミングの判断**: 石高50消費は商人にとって仲間10人分のリクルート費用。使いどころを間違えると経済破綻
- **敵密集地帯で使うと効果大**: 城下町など敵が多い場所で発動すれば、敵を一気に味方にできる
- **維持費との兼ね合い**: 買収で増えた仲間にも維持費（0.3石/人/秒）がかかる。大量買収後の経済管理が重要
- **初期石高500からのスタート**: 初期資金が少ないため、序盤の買収は慎重に

## 11. 民衆集めの仕組み

### 民衆の出現
- フィールド上に常時民衆NPCが点在
- 村・城下町エリアに多く出現
- 離脱した仲間は徘徊NPCに戻る（再勧誘可能）

### 仲間にする方法（キャラ別）
- **農民**: 勧誘範囲内で400ms説得時間。攻撃ヒット時に30%確率で民衆が追加スポーン
- **足軽**: 勧誘範囲内で200ms説得時間（最短）
- **商人**: 即時リクルート（触れるだけで仲間に、石高120消費）

### 仲間になった民衆の挙動
- プレイヤーの周囲をピクミン式に周回（オービット、半径40〜80px）
- **全キャラ共通で仲間は不死**（敵に殺されない）
- **全キャラの仲間に攻撃判定あり**（各仲間の周囲30px。農民・商人: 3ダメージ、足軽: 2ダメージ、1秒CD）
- 威圧値 + 民衆係数としてスコアに影響

## 12. 中毒性と逆転性の設計意図

### 中毒性を生む構造

1. **90秒の短さ**: 「もう1回」の心理的ハードルが極めて低い
2. **ランダムマップ**: 毎回城の位置、川の配置、民衆の分布が変わる → 同じゲームは二度とない
3. **仲間が増える快感**: ピクミン的な「周囲を取り囲む仲間が増えていく」視覚的満足感
4. **威圧による自動降伏**: 長い行列で歩くだけで敵がひれ伏す → 爽快感
5. **ルート判断の面白さ**: 「城が近い！下克上狙う？」「橋渡る？迂回する？」の即興判断
6. **キャラ変更の誘惑**: 3キャラ × ランダムマップ = 高いリプレイ性

### なぜ小学生が大人に勝てるのか

1. **考えすぎが裏目に出る**: ルート最適化を考えている間に時間が過ぎる
2. **直感的行動が報われる**: 「あの敵の群れに突っ込む」が意外と正解
3. **威圧は戦闘力不要**: 民衆を集めるだけで弱敵を倒せる → 戦闘が苦手でもスコアが伸びる
4. **ランダム性**: マップ運、辻斬りタイミング、一揆成否。どんな上手いプレイヤーでも事故る

## 13. 飛び道具の絵文字表現（キャラ別）

各キャラの通常攻撃は固有の絵文字で飛翔する:

| キャラ | 絵文字 | 回転速度 | フォントサイズ |
|--------|--------|---------|--------------|
| 農民 | 🪓（斧） | 6 rad/s | 32px |
| 足軽 | 🌙（三日月） | 6 rad/s | 32px |
| 商人 | 🧮（算盤） | 6 rad/s | 32px |

飛翔中の絵文字は6 rad/sで回転しながら飛ぶ。

## 14. ボスHP計算式

下克上チャレンジのボス（城主）HPは、ラウンドインデックスと行列人数によるHP減少で決定:

```
var hpReduction = （行列人数による減少値）;
var bossHP = Math.max(45, (90 + rIdx * 60) - hpReduction);
```

- ベースHP: 90
- ラウンド増分: +60/ラウンド
- 最低HP: 45（どれだけ行列が長くてもこれ以下にはならない）

## 15. ボス撃破演出（ロックマン風）

ボスを倒した瞬間、以下の演出が順次実行される:

1. **スローモーション開始**: ゲーム速度が0.05xに低下（2秒間）
2. **ボス点滅**: 0.08秒間隔で表示/非表示を高速トグル
3. **段階的爆発**: 0.25秒ごとにボス周辺にランダム位置で🔥エフェクトを生成
4. **白フラッシュ**: 0.8秒間、画面全体が白く明滅
5. **最終爆発バースト**: スローモーション終了と同時に6つの🔥が一斉爆発
6. **ボス消滅**: 爆発バースト後にボスが画面から消える

- HPバーはボス撃破演出中は非表示
- **endGamePendingパターン**: 演出完了を待ってからリザルト画面に遷移（演出中にゲーム終了処理が走らない）

## 16. 浮遊スコア表示（FloatingScoreSystem）

石高の増減が発生するたびに、画面上に浮遊する数値が表示される:

- **+N**: 苔色（緑系）で表示。石高獲得時
- **-N**: 朱色（赤系）で表示。石高消費時
- **地形収入**: 毎フレームではなく3秒間バッファリングしてまとめて表示（画面が数値で埋まるのを防止）
- **同時表示上限**: 最大5件。超過分は古いものから消える
- **大表示**: |amount| >= 50の場合、通常より大きいフォントで表示

## 17. 敵スポーン制御

### 城下町付近の敵スポーン抑制

城下町の中心に近いほど敵のスポーンが抑制される:

- 中心部: 70%の確率でスポーンを棄却
- 距離に応じて線形に減衰し、400px以上離れると抑制なし（0%棄却）

### 城地形での辻斬り無効

辻斬りの地形判定で、城（CASTLE）地形は発動率0を返す（城内での辻斬りは発生しない）。

## 18. 民衆スポーン（距離ベース）

民衆NPCは村・城下町の近くに優先的にスポーンする:

- スポーン位置は村/城下町からの距離に指数関数的に減衰（Math.random() * Math.random() で分布）
- maxSpawnRadius = 600px（村/城下町から600px以上離れた場所にはスポーンしない）

## 19. 2倍速モード

キャラ選択画面で**Qキーを押しながらキャラカードをクリック**すると、ゲーム全体が2倍速で進行する:

- gameState.speedMultiplier = 2
- 全てのゲームロジック（移動・攻撃・クールダウン・タイマー等）が2倍速で処理される
- 上級者向けのチャレンジモード

## 20. オンボーディング

初回プレイヤー向けのコンテキスト別チュートリアルTipsシステム:

- 操作や仕組みに関するヒントが、適切なタイミングで画面に表示される
- **和紙パネル**スタイルで表示（世界観と調和）
- 各Tipsには「もう表示しない」チェックボックスがあり、localStorageに記録
- 表示済みフラグはブラウザのlocalStorageで永続化

## 21. 衝突判定の補足

### 家屋の川衝突判定

家屋の配置時に、中心点だけでなく左右端（center +/- collisionRadius）が川と重なっていないかチェックする。中心が川の外でも端が川にかかる場合は配置を棄却。

### 家屋の城衝突判定

家屋は城地形と重なる位置にはスポーンしない（城テラインとの衝突判定あり）。

## 22. アーキテクチャ（シングルHTML実装）

### 設計思想

ゲーム全体を**独立したオブジェクト群**として単一HTMLファイル内に実装。各オブジェクトは単一責任を持ち、明確なインターフェースで接続される。

### オブジェクト一覧

```
[入力系]
  InputManager       — キーボード/マウス入力の正規化

[マップ系]
  MapGenerator        — ランダムマップの生成（地形配置アルゴリズム）
  TerrainManager      — 地形データの管理・衝突判定
  TileMapper          — Kenney RPGタイルセットのマッピング
  CameraController    — プレイヤー追従カメラ（デッドゾーン付き）

[エンティティ系]
  PlayerController    — プレイヤーの移動・状態管理
  EnemyManager        — 敵NPCのスポーン・AI・ウェーブ管理
  CivilianManager     — 民衆NPCのスポーン・勧誘判定

[行列系]
  ParadeController    — 行列の追従ロジック（ピクミン式オービット、半径40-80px、lerp 0.1）
  ParadePhysics       — 地形による行列変形（橋で一列化、草原で扇状）
  IntimidationSystem  — 威圧判定（行列長 vs 敵の気骨値）
  ParadeChargeSystem  — 行列突撃の実行と再集結

[戦闘系]
  CombatSystem        — 攻撃判定・キャラ別攻撃パターン分岐
  ProjectileManager   — 弾の生成・移動・衝突判定

[イベント系]
  TsujigiriSystem     — 辻斬りQTEの発生・カットイン演出・入力判定・カウンター/即死処理
  IkkiSystem          — 一揆の発動・仲間10%消費・全敵ダメージ計算・15秒CD管理（農民専用）
  KobuSystem          — 鼓舞の発動・5秒間攻撃速度ブースト（CD 1.0→0.3秒）・15秒CD管理（足軽専用）
  BaishuSystem        — 買収の発動・石高50消費・5秒間買収オーラ（150px）・敵味方転換・15秒CD管理（商人専用）
  GekokujoSystem      — 下克上チャレンジの城門・ボス戦・20秒撤退タイマー・成否判定（断ると5秒後に再出現）
  ShoninSystem        — 商人の経済メカニクス（地形収入・即時リクルート・維持費・離脱）

[スコア系]
  ScoreManager        — 石高の計算（敵撃破 + 威圧降伏 + イベント）
  RankSystem          — 身分の昇格判定

[演出系]
  EffectRenderer      — エフェクト（ヒット、破壊、勧誘成功）
  AnnouncementSystem  — テキスト告知（身分上昇、辻斬り警告等）。左3px アクセントバーで type 別に色分け: "good"（緑: 撃破・鼓舞・買収・下克上成就・本懐成就等）、"bad"（赤: 石高不足・農民離脱・殿様撤退等）、"announce"（黄: 辻斬り出現・下克上チャレンジ等）
  FloatingScoreSystem — 石高増減の浮遊数値表示（+N 苔色 / -N 朱色、地形収入3秒バッファ、同時最大5件、|amount|>=50で大表示）
  BossDefeatEffect    — ボス撃破ロックマン風演出（2秒スローモ0.05x、0.08s点滅、0.25s間隔の炎爆発、0.8s白フラッシュ、最終6爆発バースト）
  OnboardingSystem    — コンテキスト別チュートリアルTips（和紙パネル、localStorage「もう表示しない」チェックボックス付き）
```

### 技術選定

| レイヤー | 技術 | 理由 |
|---------|------|------|
| 描画 | **Canvas 2D** (vanilla JS) | 単一HTMLで完結。フレームワーク不要 |
| タイルセット | **Kenney Roguelike RPG Pack** | 無料・商用可。スプライトシートで一括読み込み |
| キャラスプライト | **カスタムPNG** | nomin_play, ashigaru_play, shonin_play, nobushi等 |
| ホスティング | **Firebase Hosting** | 静的ファイル配信。CDNあり |

## 補足: ゲームフィールのリファレンス

> **「Vampire Survivors の手軽さ」×「ピクミンの仲間を率いる快感」×「ローグライクのランダムマップ」を90秒に凝縮**

ランダム生成された和風フィールドを駆け回り、ピクミン式パレードで民衆を率いて敵をひれ伏させ、辻斬りから仲間を守り、城に攻め込む——90秒間に判断と操作が凝縮された、「もう1回」が止まらないゲーム体験。
