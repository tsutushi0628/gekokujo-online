## 3. Nanobananaプロンプト

### 共通スタイル指定（全プロンプトの先頭に付与）

```
ちいかわ風のシンプルでかわいいキャラクターデザイン（ちいかわのキャラクターそのものは使わない）。
丸みのあるシルエット、2〜3頭身のデフォルメ。
黒インクの細い手描き風の輪郭線、筆圧の強弱あり。
配色は最小限：白(#fafafa)ベースに黒(#1a1a1a)の線画、差し色は和風の落ち着いた色味。
グラデーション・影なし、フラットな塗りのみ。
戦国時代・江戸時代の日本の雰囲気。
```

## 4. 制作優先順位

1. **P0（まず動かす）**: プレイヤー3キャラの正面立ちポーズ + 草原タイル → 最小限の画面が作れる
2. **P1（ゲームプレイ）**: プレイヤー全方向アニメ + 敵キャラ（野盗・足軽隊） + 橋・川タイル → 戦闘が成立する
3. **P2（コンテンツ）**: 武将・城主 + 城・城下町・山道タイル + 民衆NPC → マップが完成する
4. **P3（演出）**: エフェクト全般 + リザルト背景 → 仕上げ
