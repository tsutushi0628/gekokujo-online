## 1. ゲーム概要

60秒制限のアクションゲーム。3キャラクター（足軽/商人/農民）から1体を選択し、民衆を仲間にして行列を作り、城に攻め込んで殿様を倒す「下克上」を目指す。農民のみ「一揆モード」（Z選択）が存在し、制限時間50秒・一揆ULT使用可能になる。

- 勝利条件: 下克上成功（殿様撃破）
- 敗北条件: HP=0
- 時間切れ: 通常終了（敗北ではない）

## 5. 殿様戦 (main.js:379-935 GekokujoSystem)

### 出現条件
- **ゲーム開始30秒後に城が黄色に発光**し、プレイヤーが城に接触するとダイアログ表示 (main.js:409 `scheduleTime=30`, main.js:561, main.js:577-593)
- 辞退した場合、5秒後に再挑戦可能 (main.js:589)

### 殿様ステータス (constants.js:67-87 TONO_BOSS + main.js:753-778)
- **HP: 500**（固定、全キャラ共通）(constants.js:68)
- 攻撃: 8 + rIdx × 4 （rIdx = min(rankIndex+2, 5)）(main.js:758,764)
- サイズ: 52 (main.js:768)
- 制限時間: 20秒 (main.js:756)

### AIステートマシン (main.js:488-557)

| ステート | 速度 | 行動 | 遷移 |
|---|---|---|---|
| CHASE | 2.5 | プレイヤー追跡（城エリア内のみ）、接触で1秒間隔ダメージ | 3秒後→60%WINDUP/40%CHASE |
| WINDUP | 0 | 停止、赤いオーラ脈動 | 0.8〜1.8秒後→CHARGE |
| CHARGE | 4.5 | プレイヤー方向にロック突進、接触でHP35%ダメ+ノックバック20 | 接触 or 3秒後→DECEL |
| DECEL | 4.5→1.5 | 線形減速、突進方向維持、終了時に衝撃波 | 0.5秒後→70%RETREAT/30%WINDUP |
| RETREAT | 2.8 | 城前方(standoff=160px)へ撤退、1.5秒間隔で弾丸発射(速度4,ダメージ12) | 城到着→CASTLE_WAIT |
| CASTLE_WAIT | 0 | 停止、**無敵**（弾丸・仲間攻撃無効）、青いバリア表示 | 1〜2秒後→50%WINDUP/30%CHASE/20%RETREAT |

> 参照: TONO_BOSS定数 (constants.js:67-87), 状態遷移 (main.js:525-557), CASTLE_WAIT無敵 (entities.js:805, entities.js:1018)

### 衝撃波 (DECEL終了時)
- 半径: 80px (constants.js:78)
- ダメージ: 20 (constants.js:79)
- 仲間にもヒット (main.js:700-707)

### 接触ダメージ (CHARGE時)
- HP35%ダメージ (constants.js:80 `contactDamageRatio: 0.35`)
- ノックバック力: 20 (constants.js:85)
- 1回の突進につき1回のみ（contactHitフラグ）(main.js:507,655)

### 戦闘中の特殊ルール
- ゲーム時間停止 (main.js:1535-1537)
- 敵全消去 (main.js:757)
- 辻斬り無効 (main.js:1571-1573)
- 維持費免除 (economy.js:46)

### 結果
- 成功: スロー2秒(0.05x) → 2000 + rankIndex × 1000 石高 + 身分2段階上昇 → 勝利 (main.js:782-818)
- 足軽のみ武功ボーナス: 15秒以内撃破で+2000石 (main.js:802-808)
- HP=0: ゲームオーバー (main.js:828-834)
- 時間切れ: 殿様退却、5秒後再挑戦可 (main.js:820-826)

### 城の黄色発光
- ゲート有効時（gateActive=true）に城スプライトにshadowColor="rgba(255, 220, 40, alpha)"で黄色パルス (main.js:838-847)
- alpha = 0.4 + sin(now/400) * 0.2 (main.js:840)

## 9. 城の五角形ポリゴン衝突判定 (entities.js:6-95, main.js:420-434)

城は五角形ポリゴンとして衝突判定される。

```
頂点座標（城中心cx,cyからの相対位置）:
  [cx+0,   cy-180]  ← 頂点（上）
  [cx+140, cy-60]   ← 右上
  [cx+180, cy+180]  ← 右下
  [cx-180, cy+180]  ← 左下
  [cx-140, cy-60]   ← 左上
```

> 参照: main.js:427-433

- プレイヤー・敵・弾丸すべてに適用 (entities.js:134-138)
- pointInPolygon()でポリゴン内判定 → resolvePolygonPushOut()で押し出し (entities.js:6-95)
- 弾丸はポリゴン内に入ると消滅 (entities.js:957-963)
- 殿様戦のトリガーはexpandPolygon()で城ポリゴンを(プレイヤーサイズ+20px)拡大した領域で判定 (main.js:581-583)

## マップ生成 (terrain.js / main.js)

### 地形配置
- 3×3グリッド（9ブロック、各1280×720px）(constants.js:2-7)
- 城: 左端列 or 右端列のランダム1マス
- 城下町: 城に隣接する1マス
