# 下克上オンライン — 漫画から読み取れるゲーム仕様断片

## 出典
ちいかわ（ナガノ作）単行本7巻「下克上と先生編」
連載: 2022年9月〜11月頃（Twitter/X @ngnchiikawa）

---

## 画面スクショから確定した仕様

### 1. タイトル画面
- タイトル: 「下克上 GEKOKUJO オンライン」
- キャッチコピー: 「刮目せよ 下克上を...」
- STARTボタンあり
- タイトル画面に複数キャラが描かれている（異なる装備/役割を示唆）

### 2. 下克上システム
- 「下克上成功!!」「下克上失敗.....」の2パターンが確認
- 下克上は1プレイにつき1回のチャレンジ（ゲームエンドに直結）
- 成功時: 「お主は ○○位」とランク表示
- 失敗時: ドクロマーク表示 → ゲームオーバー
- **重要**: 下克上を使わなくても高順位に到達可能（ちいかわ2位、ハチワレ3位は下克上成功の表示なし）
- 下克上はあくまで「任意のハイリスク・ハイリターンチャレンジ」であり、メインの順位上昇ルートではない

### 3. ゲームエンドの3パターン
| パターン | 画面表示 | 意味 |
|----------|----------|------|
| 通常終了（高順位） | 「お主は 33位」「お主は 3位」 | 下克上なしで到達。メインの成長ルート |
| 下克上成功 | 「下克上成功!! お主は 1021位」 | 下克上に挑んで勝ったが、実力相応の順位 |
| 下克上失敗 | ドクロ画面 | ゲームオーバー |

### 4. ランキング表示
- 「お主は 33位」「お主は 1021位」の形式
- 「お主は」= 時代劇風の二人称
- 数字は黄色で強調表示
- 集中線の演出あり

### 5. 辻斬り
- 「辻斬りにあってしまった」というメッセージ
- 画面: キャラが横から斬りつけられている描写
- 受動的イベント（プレイヤーの意志に関係なく発生）
- ランキング下降の原因になる

### 6. キャラ選択（「○○使い」）
- 「しかも農民使いだ」→ 驚きのリアクション付き
- ウサギが農民使い（意外そうな反応 = テクニカル/上級者向けキャラ）
- 「使い」という表現 → ゲーム開始時にキャラクターを選択する仕組み
- 農民は弱そうに見えて実は強い（玄人向け）という位置づけ
- 選べるのは下の身分のみ（農民、足軽など）。武将・大名は成り上がった先であり選択肢にはならない

### 7. 一揆システム
- 「一揆に参加する？」→ はい / いいえ の選択肢
- プレイヤーの任意参加（強制ではない）
- 「挑戦的！」という吹き出しが近くにある → 高リスク・高リターンの選択
- 農民使い限定（または農民使いだからこそ出現する）イベントの可能性が高い
- 農民使いがテクニカルと言われる理由: 一揆のタイミング判断と立ち回りが要求される

## ストーリーから確定した仕様

### ランキング実績
| キャラ | 経過 | 最終 | 備考 |
|--------|------|------|------|
| ちいかわ | 90位 | 2位 | 下克上なしで到達 |
| ハチワレ | 135位 | 3位 | 下克上なしで到達。途中で辻斬り被害 |
| ラッコ | - | 1021位 | 下克上成功だが低順位。リアル戦闘最強だがゲーム下手 |
| ウサギ | - | 順位不明 | 農民使い。周囲が驚くテクニカル選択 |

### その他の確定情報
- プラットフォーム: PC（インターネットコーナーのパソコン）
- 操作: マウス＋カーソルでアクション操作（FPS的な忙しい動き）
- ゲーム時間: 1回が極めて短い
- 「民衆を仲間に入れないと」→ プレイ中に仲間を集める要素あり
- ラッコ（リアル戦闘最強）がゲーム下手 → 単純な反射神経ゲームではなく戦略性がある

## 世界観・時代設定

### 混合時代劇
厳密な一時代ではなく、日本の歴史モノ要素をざっくり混ぜた世界観:
- **下克上** → 戦国時代（室町末期〜安土桃山）の概念
- **農民・一揆** → 戦国（一向一揆）〜江戸（百姓一揆）にまたがる
- **辻斬り** → 江戸時代の概念（武士が刀の試し切りで通行人を斬る）
- **「お主は」** → 時代劇全般の言い回し
- **百姓→大名への成り上がり** → 戦国時代（秀吉がモデルか）

→ 時代考証にこだわる必要はない。「なんかそれっぽい和風の世界」がコンセプト

### 身分の階層（推測）
選択できるのは下の身分のみ。上位は成り上がった結果:
- 選択可能: 農民、足軽、（商人？僧兵？野武士？）
- 成り上がり先: 侍、武将、大名、天下人…

## 操作感とジャンルの考察

### 漫画の描写から
- ちいかわ・ハチワレがマウスをガチャガチャ忙しく動かしている
- カーソルとマウスを使った明確なアクション操作
- この動きはF/TPS系の照準操作に酷似

### プラットフォーム制約
- ネカフェのPCで気軽にプレイ → ログイン不要
- ブラウザで即プレイ可能なアーケード的体験
- 1プレイ完結（セーブ不要）

### ジャンルの結論
- **ブラウザで動くアーケード型アクションゲーム**
- F/TPS的なマウスアクション操作
- PvEベース（同時接続不要、1人で遊べる）
- スコア/順位はサーバーのハイスコアボードに記録
- 「コイン入れてSTART」的な即プレイ構造

---

## 1プレイの構造（考察）

```
① キャラ選択（農民 / 足軽 / ...）
  ↓
② フィールドでアクション
  - マウスで移動＋戦闘（照準操作）
  - 民衆を仲間に集める
  - 敵を倒す → スコア/順位が上がる
  ↓
③ ランダムイベント発生
  - 辻斬り（受動・強制） → やられるとランク低下
  - 一揆（農民使い限定？） → 参加するか選択。高リスク高リターン
  ↓
④ 下克上チャレンジ（任意・1プレイ1回限り）
  - 仕掛ける → 成功で順位確定 / 失敗でゲームオーバー
  - 仕掛けない → 通常終了で到達順位が記録
  ↓
⑤ ゲームエンド
  - 「お主は ○○位」
```

## デザイン要件（プロダクトオーナー指定）

### 必須条件
1. **小学生程度でも遊べるゲーム性** - シンプルな操作、直感的なルール
2. **何回も繰り返そうと思う中毒性** - 短いプレイ時間、ハイスコア更新の快感
3. **賢い大人が小学生に負ける可能性がある逆転性** - 知識や経験だけでは勝てない設計

### 漫画との整合ポイント
- ラッコ（リアル最強）がゲーム下手 → 反射神経や力押しだけでは勝てない
- 農民使い（弱キャラ）がテクニカル → キャラ間バランスに意外性がある
- 短時間プレイ × ハイスコア更新 → アーケード的中毒性

## 未確定（デザインの余白）

### ゲームプレイの核心
- バトルの具体的な操作（何を操作しているのか。キャラ1体？軍勢？）
- フィールドの構造（マップがあるのか、アリーナなのか）
- 民衆の集め方（触れる？説得？戦闘で奪う？）
- 順位の上がり方（敵を倒す？生存時間？スコア？）
- 下克上チャレンジの具体的な内容（ボス戦？特定プレイヤーとの対戦？）

### キャラ選択
- 農民以外の選択肢（足軽は有力。他は？）
- 各キャラ固有のイベント（農民＝一揆、他は？）
- キャラ間のバランス設計

### システム
- 1プレイの制限時間の有無
- ランキングの永続性（毎回リセット？累積？）
- 装備・スキル・レベルなどRPG要素の有無

## 元ネタ考察
- ファンの間では「いっき」（FC/1985年）説あり
  - 農民＋一揆のキーワードが一致
  - ただしいっきは2Dアクション、下克上オンラインはランキング制オンライン
- 時代劇ゲーム全般のパロディの可能性（信長の野望、太閤立志伝等）
- 「○○使い」はキャラ選択型対戦ゲーム（格ゲー等）の文脈に近い
