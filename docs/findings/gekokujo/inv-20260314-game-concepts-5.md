# 下克上オンライン — ゲームコンセプト5案

全案共通:
- 漫画の確定要素（キャラ選択、下克上、辻斬り、一揆、民衆集め、ランキング）を全て包含
- **キャラは3種**（足軽/野武士/農民）。タイトル画面の3体準拠
- **地形要素**: 橋・草原・川・山道・城下町・城がフィールドに存在（漫画の描写準拠）
- **下克上 = 城への攻め込み**。フィールド奥の城に突入して城主と対決する形式
- **辻斬り被弾 = ノックバック（吹っ飛ばされる）+ 民衆離散**。漫画のプレイヤーが吹っ飛ぶ描写を再現
- WASD移動 + マウス照準のアクション操作
- PvEベース、ブラウザ即プレイ、1プレイ極めて短い
- 背景は白ベース（和紙・水墨画テイスト）
- 小学生でも遊べる / 中毒性 / 大人が子供に負ける逆転性

## 案1: トップダウン・アリーナアクション（現行設計）

> **コンセプト**: 橋・草原・城などの地形が広がる見下ろしフィールドで90秒間、奥の城を目指しながら成り上がるアーケードアクション

- **ジャンル**: トップダウン・アクション（スコアアタック）
- **最も近い既存ゲーム**: Vampire Survivors × ピクミン
- **キャラ**: 3種（足軽/野武士/農民）。タイトル画面の3体準拠
- **コアメカニクス**: WASD移動で橋・草原・山道・城下町が広がるフィールドを駆け回り、マウス照準で敵を攻撃。民衆に近づいて仲間にし、スコア倍率を上げる。フィールド奥の城に攻め込めば下克上チャレンジ。橋の上では辻斬りに遭いやすく、被弾時はノックバックで吹っ飛ばされ川に落ちるリスクも。石高（スコア）= 敵撃破 × 民衆係数。90秒の固定時間制
- **この案ならではの面白さ**: 地形を活かした立ち回りが戦略の幅を広げる。橋を渡るリスク判断、草原での民衆集め、城への突撃ルート選択。「敵を倒す時間」と「民衆を集める時間」のトレードオフが90秒の中で常に迫られる
- **技術的な難易度**: 中（Phaser 3で十分実現可能。地形タイルマップ・敵AI・民衆の群れ制御がメイン課題）

**詳細設計**: [game-design.md](./game-design.md) 参照

## 案2: ウェーブディフェンス型（拠点防衛＋出撃）

> **コンセプト**: 自分の「村」を守りながら敵の「城」に攻め込み、身分を奪い取る攻防一体の拠点ゲーム

- **ジャンル**: タワーディフェンス × アクション
- **最も近い既存ゲーム**: Kingdom: Two Crowns × Dome Keeper
- **キャラ**: 3種（足軽/野武士/農民）
- **コアメカニクス**:
  - フィールド手前にプレイヤーの「村」、奥に敵の「城」。間に橋・草原・山道が広がる
  - WASDで村と城の間を移動し、マウスで攻撃
  - 四方から敵NPCがウェーブで攻めてくる（足軽→侍→武将とウェーブごとに強化）
  - 民衆を集めて村に配置すると「防衛ユニット」として村を自動防御してくれる
  - プレイヤー自身は村を離れて敵の城に攻め込むことも可能 → ここで石高を大量獲得
  - **ジレンマ**: 村を守るか、村を民衆に任せて城攻めに出るか
  - 下克上チャレンジ = 敵の城に突入し城主と対決。村が無防備になるリスク
  - 辻斬り = 村と城の間の橋や山道でランダム発生。被弾でノックバック（吹っ飛ばされて村に戻される）
  - 一揆（農民）= 民衆防衛ユニットが一斉に攻撃ユニットに転化し城に突撃。村が空っぽになる超ハイリスク攻勢
- **この案ならではの面白さ**: 「守りの安定」と「攻めのリスク」の緊張感が常にある。地形（橋・山道）が村と城の間の移動リスクを生む。大人は防衛を固めがち→攻めが足りずスコアが伸びない。子供は無邪気に城攻めして高スコアを出す逆転が起きる
- **技術的な難易度**: 中（ウェーブ管理と防衛AI。Phaser 3で実現可能）

## 案3: ローグライク進撃型（一本道ステージ突破）

> **コンセプト**: 草原→橋→山道→城下町→城と突き進む90秒間の成り上がりラン。道中の選択が運命を分ける

- **ジャンル**: 横スクロール・ローグライトアクション
- **最も近い既存ゲーム**: Dead Cells × Downwell（を90秒に圧縮）
- **キャラ**: 3種（足軽/野武士/農民）
- **コアメカニクス**:
  - フィールドは左から右へ草原→橋→山道→城下町→城と地形が変化する道（WASDのうちWで前進・Sで後退・ADで上下移動）
  - マウス照準で前方の敵を撃破しながら進む
  - 道中に分岐が出現（上の道 / 下の道）。片方は草原で民衆が多い安全ルート、もう片方は山道で敵が多いが石高が高い危険ルート
  - 進んだ距離 × 石高 × 民衆係数 がスコア
  - **立ち止まると損**（時間経過でスコア倍率が下がる）→ 常に前進する緊張感
  - 下克上チャレンジ = 道の最奥にある城に到達し城主戦。たどり着けるか自体が勝負。勝てば大ジャンプ、負ければ即死
  - 辻斬り = 橋の上で横から斬りかかってくる浪人。被弾でノックバック（吹っ飛ばされて後退）。スペースで回避
  - 一揆（農民）= 集めた民衆が前方に突撃し道を切り開く。成功なら大量の敵を掃討、失敗なら民衆全滅
- **この案ならではの面白さ**: 地形の変化が冒険感を演出。橋は辻斬りの危険地帯だが避けて通れない。「前に進むか立ち止まるか」の判断が毎秒求められる。城に到達できること自体が達成感。大人は安全ルートを選びがち、子供は危険ルートを突っ込んで大当たりを引く
- **技術的な難易度**: 低〜中（横スクロール+分岐はシンプルな構造。地形バリエーションとステージ生成のランダム性がメイン課題）

## 案4: 見下ろしシューター型（弾幕×民衆シールド）

> **コンセプト**: 和風弾幕シューティングで敵の弾を避けながら民衆を盾にして城を目指す、攻防逆転アクション

- **ジャンル**: トップダウン・シューティング（弾幕系）
- **最も近い既存ゲーム**: Enter the Gungeon × 東方Project（をカジュアルに）
- **キャラ**: 3種（足軽/野武士/農民）
- **コアメカニクス**:
  - 草原・橋・城下町などの地形がある見下ろしフィールド。WASDで移動、マウスで照準、左クリックで弾を発射（遠距離攻撃）
  - 敵も弾を撃ってくる → 弾幕を避けながら戦うシューティング
  - **民衆 = シールド**: 仲間にした民衆がプレイヤーの周囲を回転し、敵弾を1発だけ防いでくれる（民衆1人 = 1ヒットポイント）
  - 民衆が多い = 被弾に強い = より攻撃的に立ち回れる = スコアが伸びる
  - 民衆が0人 = 1発被弾でゲームオーバー → 常に民衆を補充し続ける必要がある
  - 敵を倒すと石高獲得。ボスクラスの敵は弾幕が激しいが石高も高い
  - 下克上チャレンジ = フィールド奥の城に突入し城主（弾幕ボス）と対決。弾幕がすさまじいが、倒せば大量石高
  - 辻斬り = 橋の上で予告なしの高速斬撃。被弾でノックバック（吹っ飛ばされる）+ 民衆シールドが大量消失
  - 一揆（農民）= 民衆シールドを全て「弾」として敵に発射。全弾命中なら壊滅的ダメージ、外すとシールドゼロ
- **この案ならではの面白さ**: 民衆が「スコア倍率」ではなく「生存手段（シールド）」という物理的な意味を持つ。橋の上での辻斬りは回避スペースが狭く緊張感が高い。弾幕を避ける緊張感と、民衆を使い捨てるかキープするかの判断。シューティングは反射神経だが、民衆管理は戦略 → 両方必要。小学生は弾幕ゲームに慣れている世代（スマホSTG）で大人より上手いことが多い
- **技術的な難易度**: 中（弾の衝突判定が多いがPhaser 3のArcade Physicsで対応可。民衆の回転配置の計算が少し特殊）

## 案5: 大名行列パレード型（民衆パレード×タイミングアクション）

> **コンセプト**: 民衆の大行列を率いて草原・橋・城下町を練り歩き、敵を蹴散らしながら城を目指すパレードアクション

- **ジャンル**: パレード・アクション（リズム×アクション）
- **最も近い既存ゲーム**: Katamari Damacy（塊魂）× Patapon
- **キャラ**: 3種（足軽/野武士/農民）
- **コアメカニクス**:
  - プレイヤーは行列の先頭。草原・橋・山道・城下町・城が広がるマップをWASDで移動し、マウスで攻撃方向を指定
  - 後ろに仲間の民衆がぞろぞろ連なる（蛇のように）。民衆が多いほど行列が長くなる
  - **行列の長さ = 威圧値**: 長い行列で敵の前を通ると、弱い敵は戦わずに降伏する（石高を自動獲得）
  - 強い敵は行列を見ても怯まない → 直接戦闘が必要
  - 左クリックで攻撃、右クリックで「行列突撃」（行列全体が前方に突進。塊魂的に敵を巻き込む）
  - **橋の上の行列**: 橋は狭いため行列が一列になる → 辻斬りで分断されやすい最大の危険地帯
  - **行列突撃のリスク**: 行列がばらける → 再集結に時間がかかる。その間に辻斬りが来ると壊滅
  - 民衆を集める = 行列を長くする = 威圧で自動石高 + 突撃の威力UP
  - 下克上チャレンジ = フィールド奥の城に行列ごと突入。行列の長さと突撃のタイミングで城主を圧倒できるか
  - 辻斬り = 橋の上で行列を横から断ち切る。プレイヤーはノックバックで吹っ飛び、後方の民衆が離脱する
  - 一揆（農民）= 行列の民衆が全方向に散開して暴れる。画面上の全敵にダメージ。成功なら石高爆発＋民衆が増えて帰還、失敗なら民衆消滅
- **この案ならではの面白さ**: 「行列が長くなっていく快感」が塊魂のそれ。橋を長い行列で渡る緊張感は唯一無二。行列の管理（橋では一列に、広い草原では扇状に広がる）と地形の相互作用がパズル的。威圧による自動獲得があるので、戦闘が苦手な子供でも行列さえ長ければスコアが伸びる → 大人が戦闘力で勝っても、子供が民衆集めで勝つ展開
- **技術的な難易度**: 中〜高（行列の物理的な挙動＝スネークゲーム的な連結制御。地形に応じた行列変形。面白さは高いが実装コストも高い）

### 個人的な推薦

**案1（アリーナ）か案3（ローグ進撃）を推薦**。

- **案1**は最もバランスが良く、漫画のゲーム描写（1画面でガチャガチャ操作）に最も忠実。汎用的な面白さがある
- **案3**は開発コストが最も低く、「分岐選択のワクワク感」で中毒性が非常に高い。ローグライク的なリプレイ性は実証済みのゲームデザインパターン
- **案5**は視覚的インパクトが最も強いが実装コストが高い。ただし「行列が伸びる快感」は唯一無二で、差別化要素としては最強
