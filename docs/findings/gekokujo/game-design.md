# 下克上オンライン — ゲーム設計書（合体版: 案1+5）

## 1. ゲームコンセプト

**「和風フィールドを駆け回り、民衆の大行列を率いて成り上がれ。90秒で農民から天下人へ。」**

見下ろしアリーナアクション（案1）の操作感に、大名行列パレード（案5）の「行列が伸びていく快感」を融合。ランダム生成される広大な和風マップで、毎回異なる戦略判断が求められる。

## 2. ジャンル定義

**トップダウン・アーケードアクション（PvE・スコアアタック型）**

- 見下ろし視点のフィールドでマウスカーソルを照準として使うアクションゲーム
- 1プレイ90秒の固定時間制
- スコア＝「石高」で順位が決まるランキング制
- ブラウザ即プレイ（インストール・ログイン不要）
- **ランダムマップ生成**によるローグライク的リプレイ性

## 3. キャラ選択

ゲーム開始時に3つの「身分」から1つを選ぶ。それぞれ初期ステータスと固有能力が異なる。

> **注**: タイトル画面に描かれているキャラは3体。漫画準拠で3種とする。

### 足軽（あしがる）— 入門向け

- **コンセプト**: バランス型。クセがなく扱いやすい
- **初期攻撃力**: ★★★☆☆
- **初期移動速度**: ★★★☆☆
- **固有能力「槍衾（やりぶすま）」**: 前方扇状に広い攻撃判定。敵をまとめて薙ぎ払える
- **固有能力（右クリック）「行列突撃・槍衾」**: 行列全体が前方に突進し、先頭で扇状攻撃。再集結が速い（初心者に優しい）
- **民衆ボーナス**: 集めた民衆1人につき攻撃力+1%（標準）

### 野武士（のぶし）— アクション向け

- **コンセプト**: 攻撃特化・高速移動のアグレッシブ型
- **初期攻撃力**: ★★★★☆
- **初期移動速度**: ★★★★☆
- **固有能力「奇襲」**: ダッシュ突撃。短いクールダウンで突進→大ダメージ。当たれば強い、外すと隙だらけ
- **固有能力（右クリック）「行列突撃・奇襲」**: 行列全体が散開して奇襲。突撃威力1.8倍だが再集結が遅い（ハイリスク）
- **民衆ボーナス**: 集めた民衆1人につき攻撃力+2%（高倍率だが民衆が逃げやすい）

### 農民（ひゃくしょう）— テクニカル / 玄人向け ★

- **コンセプト**: 最弱ステータスだが「一揆」による大逆転が可能な超ハイリスク・ハイリターン型
- **初期攻撃力**: ★☆☆☆☆
- **初期移動速度**: ★★☆☆☆
- **固有能力「鍬撃ち（くわうち）」**: 攻撃は弱いが、ヒット時に確率で民衆が寄ってくる（=攻撃が勧誘を兼ねる）
- **固有イベント「一揆」**: 農民専用の大勝負イベント（後述）
- **民衆ボーナス**: 集めた民衆1人につき全ステータス+1.5%。民衆が多いほど指数関数的に強くなる「数の暴力」型
- **なぜテクニカルか**: 序盤が圧倒的に弱い。民衆を集めるまでは雑魚にも苦戦する。一揆のタイミング判断が勝敗を分ける。上手い人が使うと爆発力は全キャラ中最大

## 4. 1プレイの流れ（90秒）

```
[0秒] キャラ選択画面
  農民 / 足軽 / 野武士 から選択
  ↓
[START] ランダムマップ生成 → フィールドに出現（90秒カウントダウン開始）
  ↓
[0〜90秒] メインフェーズ ——————————————————————
  │
  ├─ 移動: WASDキーで上下左右に移動
  ├─ 照準: マウスカーソルで攻撃方向を指定
  ├─ 攻撃: 左クリックでカーソル方向に攻撃
  ├─ 行列突撃/固有能力: 右クリック（クールダウンあり）
  │
  ├─ 敵NPCを倒す → 石高（スコア）獲得 + 身分上昇
  ├─ 民衆に近づく → 仲間に加わり行列の後ろに連なる
  ├─ 行列が長いほどキャラ強化 + 弱敵が自動降伏（威圧）
  │
  ├─ [ランダム] 辻斬りイベント（橋の上で行列が分断される）
  ├─ [農民限定] 一揆イベント（行列が全方向に散開して暴れる）
  ├─ [任意] 下克上チャレンジ（城に攻め込む。1回限り）
  │
  ↓
[90秒 or ゲームオーバー] ゲームエンド
  │
  ├─ 通常終了 → 「お主は ○○位」（石高ベースのランキング表示）
  ├─ 下克上成功 → 「下克上成功!! お主は ○○位」
  └─ 下克上失敗 → ドクロ画面（ゲームオーバー）
```

## 5. コアメカニクス

### 5-1. 操作方法

| 入力 | アクション |
|------|-----------|
| WASD | キャラの移動（上下左右） |
| マウス移動 | 照準カーソルの操作（攻撃方向の指定） |
| 左クリック | カーソル方向に通常攻撃（連打可） |
| 右クリック | 行列突撃 / 固有能力発動（クールダウン: 5〜8秒） |
| スペースキー | 緊急回避（横っ飛び。短い無敵時間あり。辻斬り回避に必須） |

**操作の棲み分け**: 左クリック攻撃 + WASD移動だけで基本プレイが完結する。右クリックの行列突撃は「知ってると強い」上級テクニック。小学生は左クリック連打で楽しめ、大人は右クリックで最適化を試みる。

### 5-2. フィールド構造（ランダムマップ生成）

- トップダウン（見下ろし）視点の和風マップ
- **フィールドサイズ: 2400×1800px（画面9枚分 = 3×3グリッド）**
- **カメラ: プレイヤー追従のシームレススクロール**（デッドゾーン付きで酔い防止）
- **配色: 白ベース**の和風デザイン。和紙・水墨画テイストの明るい背景

#### ランダムマップ生成ルール

```
[マップ生成アルゴリズム]

1. フィールドを3×3の9ブロック（各800×600px）に分割

2. 城配置: 外周8ブロックからランダム1箇所
3. プレイヤー初期位置: 城から最低2ブロック離れたブロック
   （到達に歩いて約20-25秒の距離）

4. 川: 城とプレイヤーの間を横切る形で1本配置
   - 橋は2箇所:
     - 近い橋: 狭い（辻斬りリスク高、行列が一列に詰まる）
     - 遠い橋: 広い（安全だが遠回り）
   - 川は通行不可。橋でのみ渡れる

5. 草原: 2-3箇所。プレイヤー初期位置の近く（民衆密集地帯）
6. 城下町: 城の隣接ブロック（強敵密集、城のガード）
7. 山道: 城への最短ルート上1箇所（ショートカットだが敵が強い）
8. 村: 1-2箇所（民衆リスポーン地帯、安全）
9. 田畑: 草原に隣接（農民使い時に民衆が集まりやすい）
```

#### UI: ミニマップ + 城方向矢印

- **右上にミニマップ常時表示**（128×96px）
  - 城 = 赤アイコン
  - 自分 = 白点
  - 民衆密集地 = 緑点
  - 橋 = 茶色の線
- **画面端に城方向の矢印**を常時表示（コンパス的UI）
- 城の位置は最初からミニマップで見える（「探す」時間をゼロにする）
- 面白いのは「城は見えてる。でもどうやって到達するか」のルート判断

### 5-3. 敵NPC

身分の階層に対応した敵が出現する。ウェーブ的段階強化（30秒ごと）:

| 敵 | 出現ウェーブ | 石高 | 威圧で降伏する行列長 | 特徴 |
|----|------------|------|-------------------|------|
| 野盗 | 第1波（0-30秒） | 少 | 4人以上 | 弱い。チュートリアル的存在 |
| 足軽隊 | 第2波（30-60秒） | 中 | 11人以上 | 数で来る。囲まれると危険 |
| 侍 | 第2波〜第3波 | 多 | 降伏しない | 強い単体。攻撃パターンの見極めが必要 |
| 武将 | 第3波（60-90秒） | 大 | 降伏しない | 強敵。倒せば一気に石高ジャンプ |
| 城主 | 下克上チャレンジ | 特大 | — | 下克上の対象（後述） |

**ウェーブ演出**: 30秒ごとに太鼓の音で「次の波が来る」と告知。90秒に3幕のドラマを作る。

**身分上昇**: 累計石高に応じてプレイヤーの身分が自動で上がる（農民→足軽→侍→武将→大名→天下人）。身分が上がると基礎ステータスにボーナス。

### 5-4. 民衆と行列システム（案5融合の核心）

#### 行列の基本挙動

- 仲間にした民衆はプレイヤーの後ろに**スネーク式の行列**として連なる
- 各民衆は先頭（プレイヤー）の移動軌跡を追従する（蛇のように）
- 行列が長くなるほど視覚的な満足感が増す（塊魂的快感）

#### 地形と行列のインタラクション

| 地形 | 行列の挙動 |
|------|-----------|
| 草原 | 自由に広がる。民衆との距離が少し開く（扇状に） |
| 橋 | **一列に詰まる**。辻斬りで分断されるリスク最大。最も緊張する地形 |
| 山道 | やや一列化。速度は維持 |
| 城下町 | 密集。敵との衝突で民衆が離脱しやすい |

#### 威圧システム（案5由来）

```
威圧値 = 行列の人数

判定: 行列の人数 > 敵の「気骨値」 → 敵が白旗降伏（戦闘なしで石高自動獲得）
  - 野盗: 気骨値 3（行列4人以上で降伏）
  - 足軽隊: 気骨値 10（行列11人以上で降伏）
  - 侍: 降伏しない（気骨値 999）
  - 武将: 降伏しない（気骨値 999）
```

**降伏演出**: 弱敵が行列を見て白旗を掲げ、ひれ伏す → 自動で石高獲得。長い行列で歩くだけでスコアが入る快感。

#### 行列突撃（右クリック）

- 行列全体が前方に突進し、接触した敵にダメージ
- 突撃後、行列がばらける → 再集結に数秒かかる（その間無防備）
- キャラごとに突撃の挙動が異なる（5-1参照）
- **上級テクニック**: 使わなくても基本プレイは成立する

#### 行列分断（辻斬り被弾時）

- 辻斬りが行列を横切ると、切断点より後ろの民衆が離脱
- 離脱した民衆は一定時間フィールドに残る → 戻って再勧誘可能
- 橋の上での分断が最も壊滅的（一列に詰まっているため切断点が深い）

### 5-5. スコア（石高）計算

```
最終石高 = (敵撃破石高 + 威圧降伏石高 + イベントボーナス) × 民衆係数 × 身分ボーナス

民衆係数 = 1.0 + (行列の人数 × キャラ固有倍率)
身分ボーナス = 現在の身分に応じた倍率（農民1.0 → 天下人3.0）
```

**ポイント**: 威圧による自動獲得と直接戦闘の両方がスコアに貢献。行列を育てる「民衆集め」と敵を倒す「戦闘」のバランスが高スコアの鍵。

### 5-6. ランキング

- 石高を全プレイヤーの中で順位づけ → 「お主は ○○位」
- ランキングは永続（累積ハイスコアボード）
- ログイン不要: ニックネーム入力のみ（3〜8文字、和風推奨）

## 6. 下克上チャレンジの仕組み

### 発生条件
- ランダムマップのどこかに配置された**城**に近づく
- 城門に近づくと「下克上を仕掛ける？」→ はい / いいえ の選択（1プレイにつき1回限り）
- ミニマップで城の位置は最初からわかる。到達ルートの判断がゲーム性

### 挑戦内容
- 「はい」を選ぶと城内ステージに突入。城主（ボスNPC）との1対1バトル
- 城主の強さはプレイヤーの身分の2段階上に固定
- **制限時間15秒**以内に城主を倒す
- **行列の人数が城主のHP減少に寄与**: 行列が長いほど城主のHPが低い（行列を維持したまま城に到達するモチベーション）

### 成功時
- 城主の石高を総取り + 身分が2段階ジャンプ
- 「下克上成功!!」の演出（集中線）→ 石高で順位確定 → ゲームエンド

### 失敗時
- 15秒以内に倒せない or 城主に倒される → 「下克上失敗.....」
- ドクロ画面 → ゲームオーバー（石高は記録されない）

### 戦略的ジレンマ
- 行列を長く育てて城に行く → 城主が弱い（行列HP減少）が、橋で辻斬りリスク
- 行列なしで速攻 → 城主が強い。民衆係数も低いのでスコアが伸びない
- 挑まない → 90秒フルに使って堅実にスコアを稼ぐ（ちいかわ・ハチワレルート）
- **ルート判断**: 城が近い回は下克上を狙い、遠い回は堅実プレイ。マップ運もゲーム性

## 7. 辻斬りの仕組み

### 発生
- 1プレイ中に1〜3回、ランダムなタイミングで発生
- **橋の上で発生率が大幅に上昇**（漫画では橋の上で辻斬りに遭っている）
- 画面端から辻斬り浪人が高速で突っ込んでくる
- 「！」マークが0.5秒だけ表示される（予告）

### 回避
- 「！」を見てからスペースキー（緊急回避）で避けられる
- 回避成功 → ペナルティなし

### 被弾
- 「辻斬りにあってしまった」のメッセージ
- **ノックバック**: プレイヤーが大きく吹っ飛ばされる（漫画の描写準拠）
- **行列分断**: 辻斬りの切断線より後ろの民衆が離脱
- **橋の上での辻斬り**: 一列に詰まった行列が深い位置で分断される。最も壊滅的

## 8. 一揆の仕組み（農民専用）

### 発生条件
- **農民使い限定**イベント
- 行列の民衆が**10人以上**いるときにランダムで発生
- 「一揆に参加する？」→ はい / いいえ の選択

### 「はい」を選んだ場合 — 一揆フェーズ（10秒間）
- **行列の民衆が全方向に散開して暴れる**（歴史的な一揆のイメージに最も忠実な表現）
- 画面上の全敵にダメージを与える
- プレイヤーはマウスカーソルで民衆の突撃方向を誘導

### 一揆の結末
- **成功（敵を一定数以上倒した）**: 大量石高ボーナス + 民衆がさらに増えて行列に帰還
- **鎮圧（倒しきれなかった）**: 民衆が**全滅**。行列がゼロに。壊滅的ダメージ

### 「いいえ」を選んだ場合
- イベントは消え、通常プレイ続行。ペナルティなし

## 9. 民衆集めの仕組み

### 民衆の出現
- フィールド上に常時10〜20人の民衆NPCが点在
- 草原・村・田畑エリアに多く出現
- 倒された民衆は時間経過で別の場所にリスポーン

### 仲間にする方法
- プレイヤーが民衆に一定距離まで近づく → 頭上に「？」
- さらに近づいて0.5秒そばにいる → 「！」に変わり行列の最後尾に加わる
- **農民**: 攻撃ヒット時に確率で民衆が寄ってくる + 勧誘範囲が広い

### 仲間になった民衆の挙動
- プレイヤーの後ろにスネーク式行列として連なる
- 直接戦闘はしない（一揆時・行列突撃時を除く）
- 威圧値 + 民衆係数としてスコアに影響
- 辻斬り被弾時に行列が分断される

## 10. 中毒性と逆転性の設計意図

### 中毒性を生む構造

1. **90秒の短さ**: 「もう1回」の心理的ハードルが極めて低い
2. **ランダムマップ**: 毎回城の位置、川の配置、民衆の分布が変わる → 同じゲームは二度とない
3. **行列が伸びる快感**: 塊魂的な「増えていく」視覚的満足感
4. **威圧による自動降伏**: 長い行列で歩くだけで敵がひれ伏す → 爽快感
5. **ルート判断の面白さ**: 「城が近い！下克上狙う？」「橋渡る？迂回する？」の即興判断
6. **キャラ変更の誘惑**: 3キャラ × ランダムマップ = 高いリプレイ性

### なぜ小学生が大人に勝てるのか

1. **考えすぎが裏目に出る**: ルート最適化を考えている間に時間が過ぎる
2. **直感的行動が報われる**: 「あの敵の群れに突っ込む」が意外と正解
3. **威圧は戦闘力不要**: 民衆を集めるだけで弱敵を倒せる → 戦闘が苦手でもスコアが伸びる
4. **ランダム性**: マップ運、辻斬りタイミング、一揆成否。どんな上手いプレイヤーでも事故る
5. **ラッコ問題の解答**: 戦闘特化で民衆を無視 → 民衆係数1.0 + 威圧ゼロ = スコアが伸びない

## 11. アーキテクチャ（マイクロサービス的function分離）

### 設計思想

ゲーム全体を**独立したfunction群**として設計する。各functionは単一責任を持ち、明確なインターフェースで接続される。これにより:
- バグの影響範囲が限定される
- 各functionを独立してテスト可能
- 並行開発が容易

### function一覧

```
[入力系]
  InputManager       — キーボード/マウス入力の正規化

[マップ系]
  MapGenerator        — ランダムマップの生成（地形配置アルゴリズム）
  TerrainManager      — 地形データの管理・衝突判定
  CameraController    — プレイヤー追従カメラ（デッドゾーン付き）
  MinimapRenderer     — ミニマップの描画

[エンティティ系]
  PlayerController    — プレイヤーの移動・状態管理
  EnemyManager        — 敵NPCのスポーン・AI・ウェーブ管理
  CivilianManager     — 民衆NPCのスポーン・勧誘判定

[行列系]
  ParadeController    — 行列の追従ロジック（スネーク式連結）
  ParadePhysics       — 地形による行列変形（橋で一列化、草原で扇状）
  ParadeSplitter      — 行列の分断と再結合ロジック
  IntimidationSystem  — 威圧判定（行列長 vs 敵の気骨値）
  ParadeChargeSystem  — 行列突撃の実行と再集結

[戦闘系]
  CombatSystem        — 攻撃判定・ダメージ計算
  ProjectileManager   — 弾の生成・移動・衝突判定

[イベント系]
  TsujigiriSystem     — 辻斬りの発生・警告・実行・行列分断
  IkkiSystem          — 一揆の発生・実行・成否判定（農民専用）
  GekokujoSystem      — 下克上チャレンジの城門・ボス戦・成否判定

[スコア系]
  ScoreManager        — 石高の計算（敵撃破 + 威圧降伏 + イベント）
  RankSystem          — 身分の昇格判定
  RankingManager      — ランキングの保存・表示（localStorage / Firestore）

[演出系]
  EffectRenderer      — エフェクト（ヒット、破壊、勧誘成功）
  AnnouncementSystem  — テキスト告知（身分上昇、辻斬り警告等）
  ResultRenderer      — ゲームエンド画面（通常/下克上成功/下克上失敗）
  ConcentrationLines  — 集中線演出

[統括]
  GameDirector        — ゲーム全体の状態管理・フェーズ遷移・タイマー
  SceneManager        — シーン管理（タイトル→キャラ選択→メイン→リザルト）
```

### 技術選定

| レイヤー | 技術 | 理由 |
|---------|------|------|
| ゲームエンジン | **Phaser 3** (TypeScript) | ブラウザ向け2Dゲーム定番。カメラ追従が標準機能 |
| フロントエンド | **Vite + TypeScript** | HMRで開発効率が高い |
| ランキングAPI | **Firebase Cloud Functions** | 既存インフラ活用 |
| ランキングDB | **Firestore** | リアルタイム更新、サーバーレス |
| ホスティング | **Firebase Hosting** | 静的ファイル配信。CDNあり |

## 補足: ゲームフィールのリファレンス

> **「Vampire Survivors の手軽さ」×「塊魂の行列が伸びる快感」×「ローグライクのランダムマップ」を90秒に凝縮**

ランダム生成された和風フィールドを駆け回り、民衆の行列を率いて敵をひれ伏させ、辻斬りから行列を守り、城に攻め込む——90秒間に判断と操作が凝縮された、「もう1回」が止まらないゲーム体験。
