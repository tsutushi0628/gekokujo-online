# 最終バランス調整 設計書

**作成日**: 2026-03-15
**ステータス**: チーム分析セッション確定

---

## 背景

- 90秒のアーケードゲームにおいて、Q能力（CD15秒）は実質的に使われない
- 漫画原作で「農民使い」が驚かれる＝農民自体がテクニカルキャラ
- 「一揆に参加する？ はい/いいえ」は漫画の確定仕様

---

## 変更1: 足軽・商人のQ能力削除

90秒ゲームにCD15秒のアビリティは機能しない。Apex等のアビリティゲームは最大15分＝CDが回る前提の設計であり、90秒では根本的に成立しない。Q能力を削除し、基礎ステータスに補填する。

### 足軽: 鼓舞（KobuSystem）削除

| パラメータ | 変更前 | 変更後 |
|-----------|--------|--------|
| attack | 6 | 7 |
| attackCD | 1.0秒 | 0.7秒 |

### 商人: 買収（BaishuSystem）削除

| パラメータ | 変更前 | 変更後 |
|-----------|--------|--------|
| startKoku | 500 | 650 |
| followerBonus | 0.007 | 0.012 |
| 維持費 | 0.3 石/人/秒 | 0.2 石/人/秒 |

## 変更2: 一揆参加ダイアログ

### 表示タイミング

農民選択後、ゲーム開始前に表示する。

### UI構成（モック準拠）

```
┌─────────────────────────┐
│                         │
│   💬「一揆に参加する？」   │
│                         │
│    nomin_play2.png       │
│   （旗持ち農民スプライト） │
│                         │
│   [ はい ]  [ いいえ ]    │
│                         │
└─────────────────────────┘
```

### 分岐

- **はい** → 一揆モード開始
- **いいえ** → 通常農民モード

---

## 変更3: 一揆モード（農民限定）

ハイリスク・ハイリターンのモード。短い時間でスコア1.8倍を稼ぐ。

| 項目 | 値 |
|------|-----|
| Q能力 | 一揆AoE（IkkiSystem）使用可能 |
| スコア倍率 | x1.8 |
| 制限時間 | 60秒（通常90秒から短縮） |
| 殿様逃亡タイマー | 60秒経過で「殿様は逃げた...」→ リザルト |

---

## 変更4: 非一揆農民

| 項目 | 値 |
|------|-----|
| Q能力 | 無効（HUDにQスロット非表示） |
| 制限時間 | 通常の90秒 |

**メリット**: 安定したプレイ、テクニカルな立ち回りで上位到達可能。recruitTime最短（400ms）の仲間集め特化ビルド。

---

## HUD変更

|------------|----------|
| 足軽 | 非表示 |
| 商人 | 非表示 |
| 一揆農民 | 表示（一揆AoE） |

---

## 設計根拠

1. **CDが回らない問題**: Apex等のアビリティゲームは最大15分＝CDが回る。90秒では回らない。Q能力は足軽・商人にとって死にスキル
2. **原作整合性**: 漫画でウサギが「農民使い」で驚かれている＝一揆選択前の時点でテクニカル。農民の特殊性は原作で裏付けられている
3. **キャラ多様性**: 一揆あり/なしで実質4キャラの多様性を確保（足軽・商人・一揆農民・非一揆農民）
4. **ビルド差別化**: 非一揆農民 = recruitTime最短（400ms）の仲間集め特化ビルド。一揆農民 = AoE火力特化。プレイスタイルの選択肢が明確
