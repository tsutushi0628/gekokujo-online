# 下克上オンライン バランス分析レポート

最終更新: 2026-03-16

---

## 1. 分析概要

ゲームバランスの定量分析のため、2種類のシミュレーションツールを構築した。

1. **数式シミュレータ** (`scripts/score-simulator.js`) -- モンテカルロ法による数理モデル
2. **ヘッドレスゲームシミュレータ** (`scripts/headless-sim/`) -- 実ゲームロジックを忠実に移植したAIプレイヤーシミュレータ

### 設計意図（目標バランス）

| 指標 | 目標 |
|------|------|
| 平均スコア | 全キャラでほぼ均等 |
| 最大スコア順 | 足軽 < 商人 << 農民Q無 <<< 農民Q有 |
| 最小スコア順 | 農民Q有 <<< 農民Q無 < 商人 < 足軽 |
| スコアレンジ | 足軽(安定) < 商人 < 農民Q無 < 農民Q有(ハイリスク) |
| ボス撃破率 | 約70% |
| 天下人到達率 | 約80% |

## 2. 使用ツール

### 2.1 数式シミュレータ (scripts/score-simulator.js)

- モンテカルロ法によるKokuRewardの乱数シミュレーション
- シナリオベース（消極/標準/積極）
- 高速（500試行で1秒未満）
- **制約**: 空間モデリングなし、抽象パラメータによる近似

### 2.2 ヘッドレスゲームシミュレータ (scripts/headless-sim/)

- 実ゲームロジックの忠実な移植
- 3段階スキルレベル（low/mid/high）のAIプレイヤー
- 空間シミュレーション（2Dマップ、地形、移動、衝突判定）

| ファイル | 役割 |
|----------|------|
| [engine.js](scripts/headless-sim/engine.js) | ゲームエンジン（マップ生成、エンティティ、戦闘、経済、ボスAI） |
| [ai-player.js](scripts/headless-sim/ai-player.js) | AI意思決定（優先度ステートマシン） |
| [runner.js](scripts/headless-sim/runner.js) | オーケストレーションと統計集計 |

## 4. 数式シミュレータの結果

### 4.1 現行パラメータ（混合スキル: 30%低/50%中/20%高）

| キャラ | 平均スコア | 最小スコア | 最大スコア | ボス撃破率 | 天下人到達率 |
|--------|-----------|-----------|-----------|-----------|-------------|
| 足軽 | 16,512 | 6,420 | 30,864 | 100% | 33% |
| 商人 | 19,415 | 13,578 | 30,988 | 100% | 46% |
| 農民Q無 | 19,354 | 9,450 | 31,177 | 100% | 64% |
| 農民Q有 | 20,411 | 12,524 | 34,173 | 70% | 56% |

### 4.2 数式シミュレータの限界

- 抽象的な「attackShare」「recruitRate」を使用しており、実際の空間シミュレーションがない
- プレイヤーの位置取り、移動時間、地形ナビゲーションをモデル化できない
- 一部キャラのボス撃破率が非現実的に高い（足軽/農民で100%）
- スキルレベルはシナリオパラメータとしてモデル化されており、実際のゲームプレイ判断を再現しない

## 5. ヘッドレスシミュレータの結果

### 5.1 スキル別結果

| 農民Q無 | 8,772 | 4% | 78% |
| 農民Q有 | 11,990 | 0% | 57% |

#### MID skill（100試行）

| キャラ | 平均スコア | ボス撃破率 | 死亡率 |
|--------|-----------|-----------|--------|
| 足軽 | 6,277 | 15% | 74% |
| 商人 | 11,311 | 0% | 92% |
| 農民Q無 | 6,065 | 0% | 95% |
| 農民Q有 | 7,595 | 0% | 89% |

#### LOW skill（100試行）

| キャラ | 平均スコア | ボス撃破率 | 死亡率 |
|--------|-----------|-----------|--------|
| 足軽 | 3,027 | 0% | 97% |
| 商人 | 13,663 | 0% | 62% |
| 農民Q無 | 715 | 0% | 99% |
| 農民Q有 | 4,298 | 0% | 89% |

### 5.2 発見されたバランス傾向

**1. 商人はLOWスキルで最強**

テリトリー収入と自動傭兵により、プレイヤースキルに依存せずスコアが安定する。LOWスキルでの平均13,663石は全キャラ中最高であり、事実上の「初心者向けキャラ」として機能している。

**2. 足軽はHIGHスキルでボス適性最強**

5発扇攻撃による高DPSでボス撃破率85%を達成。他キャラは6%以下であり、ボス撃破能力に極端な格差がある。

**3. 農民Q無のLOWは壊滅的**

死亡率99%、平均715石。リクルート遅延、単発攻撃、被ダメージ1.4倍の三重苦により、低スキルプレイヤーにはほぼプレイ不可能。

**4. 農民Q有のレンジが最大**

HIGH skillでの最大値43,361石 -- ALL-KILL一揆により天井が非常に高い。設計意図の「ハイリスク・ハイリターン」に最も近い。

**5. 死亡率が全体的に高い**

MIDスキルの商人92%、農民95%はゲームの難易度が高すぎるか、AI回避行動が不十分であることを示唆している。

### 5.3 現行精度の課題

- 全体スコアが実ゲーム想定値の約50%に留まっている（弾ヒット率・リクルート効率のキャリブレーションが必要）
- 足軽以外のボス撃破率が極端に低い（商人・農民のDPSがシミュレーション上不十分）
- 死亡率がAI行動品質に依存して膨張している可能性がある
- 辻斬りイベントが全テストで0件（発生条件の移植漏れの疑い）

## 6. 提案されたバランス変更

### 6.1 一揆ALL-KILL化

| 項目 | 内容 |
|------|------|
| 現状 | 画面内（カメラビューポート）の敵のみ撃破 |
| 提案 | フィールド上の全スポーン済み敵を撃破 |
| 効果 | 農民Q有のスコア天井を大幅に引き上げ（平均への影響は軽微） |
| 根拠 | 行列の50%を消費するリスクに見合う「必殺技」としてのリターンを確保する |

### 6.2 パラメータ調整候補

最適探索（S9 + ALL-KILL + 平均均等化）から得られた最有力候補:

| パラメータ | 現行値 | 提案値 | 根拠 |
|-----------|--------|--------|------|
| farmer.scoreMultiplier | 1.4 | 0.9-0.95 | 平均スコア均等化 |
| merchant.scoreMultiplier | 1.2 | 1.0-1.05 | 平均スコア均等化 |
| ikkiQMult | 2.6 | 2.0-3.0 | ALL-KILL化により低倍率でも十分な効果 |
| tonoBoss.hp | 500 | 680-700 | ボス撃破率を目標70%に近づける |
| tenka threshold | 12,000 | 20,000 | 天下人到達率を目標80%に近づける |
| bukoBaseReward | 2,000 | 500-1,500 | 足軽の天井アドバンテージを抑制 |
| farmer.maxEnemies | 17 | 14 | フィールド圧力の正規化 |

### 6.3 構造的制約（パラメータでは解決できない課題）

**1. 足軽のQ能力（鼓舞）がデッドコード**

足軽に固有の強みが武功ボーナスしかない。他キャラがQ能力を持つ以上、足軽にも発動可能なQ能力を実装しなければ、スキルキャップに構造的な上限が生じる。

**2. 商人のQ能力（買収）がデッドコード**

商人の差別化がテリトリー経済のみとなっている。買収が機能すれば、敵を味方に転換する独自の戦略軸が生まれる。

**3. 殿様HPを上げると商人が最初に脱落する**

商人のDPSが構造的に低い（attack=2, chargeMultiplier=0.5）。ボスHPの引き上げは足軽以外の撃破率を壊滅的に下げるため、商人・農民のボス戦DPSの底上げか、ボス戦メカニクス自体の再設計が必要。

## 8. ツール使用方法

### 数式シミュレータ

```bash
node scripts/score-simulator.js --trials=500
```

### ヘッドレスシミュレータ

```bash
# 混合スキルで200試行
node scripts/headless-sim/runner.js --trials=200 --skill=mixed

# 特定キャラ・スキルで詳細ログ
node scripts/headless-sim/runner.js --trials=1 --skill=high --char=ashigaru --verbose

# パラメータ変更テスト
node scripts/headless-sim/runner.js --trials=100 --params=custom-params.json
```

### バランス探索

```bash
node scripts/equal-avg-search.js   # 平均均等化探索
node scripts/ikki-allkill-test.js  # ALL-KILL一揆テスト
```
