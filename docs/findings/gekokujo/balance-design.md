# 下克上オンライン バランス設計書

最終更新: 2026-03-15

---

## 設計思想

**「幅＝難易度」** — キャラごとにスコアレンジの幅を変え、幅が広いほどハイリスク・ハイリターンとする。

3つの単調性を同時に満たす:

1. **下限（高→低）**: 足軽 > 商人 > 農民Z無 > 農民Z有
2. **幅（小→大）**: 足軽 < 商人 < 農民Z無 < 農民Z有
3. **上限（低→高）**: 足軽 < 商人 < 農民Z無 < 農民Z有

安定キャラ（足軽）は下限が高く幅が狭い＝安全だが天井も低い。
リスクキャラ（農民Z有）は下限が低く幅が広い＝ハイリスクだが天井も高い。

## 変更パラメータ一覧

### 1. スコア倍率（新規追加）

全koku加算箇所（9箇所）に適用する。

| キャラ | 倍率 |
|---|---|
| 足軽 | ×1.0 |
| 商人 | ×1.2 |
| 農民 | ×1.4 |

**適用箇所:**
- entities.js:843 — 弾丸で敵撃破
- entities.js:666 — フォロワーで敵撃破
- combat.js:141 — 突撃で敵撃破
- entities.js:295 — 威圧(降伏)で敵撃破
- main.js:155 — 一揆ULTで敵撃破
- combat.js:393 — 辻斬りQTE成功
- main.js:332 — 橋ボス撃破
- main.js:583 — 下克上成功
- economy.js:42 — 商人テリトリー収入

**実装方針:** constants.jsのCHAR_DEFSに `scoreMultiplier` を追加。koku加算時に `Math.floor(value * scoreMultiplier)` を適用。

### 2. 被ダメージ倍率（新規追加）

プレイヤー本体のみに適用。フォロワーは対象外。

| キャラ | 倍率 |
|---|---|
| 足軽 | ×1.0 |
| 商人 | ×1.2 |
| 農民 | ×1.4 |

**実装方針:** constants.jsのCHAR_DEFSに `damageTakenMultiplier` を追加。プレイヤーへのダメージ計算時に適用。

### 3. 殿様HP — 700固定（全キャラ共通）

**現行:** `max(45, (90 + min(rankIndex+2, 5) * 60) - paradeLength * 3)`
**変更後:** `700`（固定値）

main.js:549を変更。

### 4. 足軽「武功ボーナス」（新規メカニクス）

殿様戦開始から15秒以内に殿様を撃破すると +200石。

- 殿様戦開始時にタイマー開始
- 撃破時に経過時間を判定
- 足軽のみ適用

**設計意図:** 足軽のスコアレンジ幅を100→300に拡大し、スキル要素を付与する。

### 5. 自動傭兵上限 — 12人

**現行:** 上限なし（koku>=30で無限に自動雇用）
**変更後:** パレード人数12人以上で自動傭兵停止

economy.js:67-68を変更。

### 6. koku=0離脱速度 — 3秒

**現行:** 1秒ごとに末尾メンバー離脱
**変更後:** 3秒ごとに末尾メンバー離脱

economy.js を変更。商人のフロア安定化が目的。

### 7. 農民スポーンパラメータ

**現行（全キャラ共通）:** maxEnemies=12, spawnInterval=3秒
**変更後（農民選択時）:**

| パラメータ | 値 |
|---|---|
| maxEnemies | 16〜18 |
| spawnInterval | 2秒 |

entities.js:198,277-280を変更。農民選択時のみ敵が多く沸き、スコア幅を広げる。

**実装方針:** constants.jsのCHAR_DEFSに `maxEnemies` と `spawnInterval` を追加。足軽・商人はnullで現行値を維持。

### 8. 一揆モード×1.8常時 — 廃止

**現行:** 農民でゲーム開始時にikkiMode=trueで全撃破が×1.8
**変更後:** ikkiMode自体を廃止。×1.8はULTウィンドウ中のみ適用（下記参照）

main.js:102のikkiModeチェックを削除。

### 9. 一揆ULTシステム改修

| パラメータ | 現行値 | 変更後 |
|---|---|---|
| クールダウン | 15秒 | 10秒 |
| 消費 | パレードの10% | パレードの25% |
| 倍率 | ×1.8（常時） | ×2.6（ULT窓のみ） |
| 窓時間 | なし（常時） | ULT発動後の一定時間 |

main.js:123-174を変更。

### 10. ゲーム制限時間

| モード | 現行 | 変更後 |
|---|---|---|
| 通常 | 90秒 | 60秒 |
| 一揆（農民Z有） | 60秒 | 50秒 |

- 商人のテリトリー収入レート
- 敵ステータス（HP, attack, speed, scoreValue）
- 身分システム（閾値、bonus値）
- 橋ボスステータス
- 辻斬りシステム
- 突撃システム
- 降伏システム
- 殿様の攻撃・速度・サイズ
- 殿様のボーナス石高: 200 + rankIndex * 100
- 殿様の制限時間: 20秒
- 殿様戦中のゲーム時間停止
