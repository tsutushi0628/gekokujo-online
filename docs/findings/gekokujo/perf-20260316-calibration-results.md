# 下克上オンライン キャリブレーション結果

作成日: 2026-03-16

## 概要

ヘッドレスシミュレーター（`scripts/headless-sim/engine.js`）を使用した統計データと、
Playwright によるブラウザ実ゲームの UI 動作確認を記録する。

---

## タスク1: engine.js バグ修正

### 修正内容

#### 修正1: 辻斬り範囲制限の撤去

`engine.js` L1579-1580 に独自追加されていた 150px 範囲制限を削除。

```js
// 削除前
const tDistSq = tdx * tdx + tdy * tdy;
if (tDistSq > 22500) { continue; } // 150px range

// 削除後 → 距離チェックなし（実ゲームのグローバル判定に合わせる）
```

#### 修正2: 敵スポーン数を2体に修正

`engine.js` L991 の `enemies.length < 6` 時のスポーン数を3体→2体に修正。

```js
// 修正前
if (this.enemies.length < 6) { this._spawnEnemy(); this._spawnEnemy(); this._spawnEnemy(); }

// 修正後（実ゲーム main.js L1434-1435 に合わせる）
if (this.enemies.length < 6) { this._spawnEnemy(); this._spawnEnemy(); }
```

## タスク2: Playwright キャリブレーション

### 環境

- サーバー: http://localhost:5173
- ブラウザ: Playwright (Chromium)
- 日付: 2026-03-16

### UI 動作確認

Playwright でブラウザを開き、以下を確認した:

- タイトル画面: STARTボタン、遊び方、クレジットリンクが表示される
- ゲームは `GameDirector.init()` を JS コンソールから直接呼び出すことで起動可能
- `gameState.koku` でリアルタイムスコアを取得可能
- `GekokujoSystem.gekokujoWin` で殿様撃破フラグを取得可能
- 操作なしで開始するとプレイヤーは即座に辻斬りや敵に倒される（スコア 0 で死亡画面）

実際のプレイ操作（WASD + マウス）が必要なため、自動プレイは困難。
以下はヘッドレスシミュレーターによるデータを使用する。

## 所見

### 修正の影響

1. **辻斬り範囲制限撤去**: 農民Q無の辻斬り成功数が大幅増加（224件）。農民は辻斬りを多用する戦略が有効になった。
2. **スポーン数修正 (3→2体)**: 序盤の敵密度が下がり、足軽の死亡率が若干改善された可能性がある。

### キャラバランスの傾向

- **商人**: 最低スコア保証あり（5,349石〜）。安定したゲームプレイが特徴。
- **農民Q無**: 低スキルでは極めて低スコア（508石）だが、高スキルでは最大29,028石まで伸びる。リスク/リターンが高い。
- **農民Q有**: 最大スコア42,813石（全キャラ最高）。ただし中スキルでは農民Q無に劣る場合もある。
- **足軽**: 商人より最低保証がなく不安定。高スキルでは8,771石と伸びしろあり。

### 課題

- Min順序チェックが NG（商人以外の最低スコアが0）: 足軽・農民は序盤に死亡するとスコアが0になる仕様上の問題。ゲームバランス上の問題ではない。
