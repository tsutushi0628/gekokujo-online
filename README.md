# 下克上オンライン

戦国時代の日本を舞台にした、ブラウザで遊べるアクションゲーム。
身分も運命も、己の手で変えろ。

**▶ [今すぐ遊ぶ](https://gekokujo-online.web.app)**

---

## ゲームの目的

1. 城の殿様を倒して **下克上** を果たせ。
2. 道中で稼いだ **石高（こくだか）** がそのままスコアになる。
3. **ランキング** で上位を目指せ！


---

## 身分

ゲーム開始時に身分を選ぶ。戦い方がまるで変わる。

| 身分 | 特徴 | 難易度 |
|------|------|--------|
| 足軽 | 前方扇状5発攻撃。戦闘の基本が学べる入門向け | 入門 |
| 商人 | 金で傭兵を即リクルート。初期石高650で開始 | 中級 |
| 農民 | 仲間の数が力。一揆に参加するを選択すれば画面一掃の必殺技つき | 最高 |

---

## 操作方法

| キー | 操作 |
|------|------|
| `W` `A` `S` `D` | 移動 |
| 左クリック | 攻撃 |
| 右クリック | 仲間で突撃（3人以上） |
| `SPACE` | 辻斬りを撃退 |
| `Q` | 一揆発動（農民・一揆ありモードのみ） |

---

## ゲームシステム

**称号**
石高を稼ぐほど称号が上がる。農民から始まり、足軽・侍・武将・大名を経て最上位の**天下人**へ。称号が高いほど石高倍率が上がるため、終盤の立ち回りほど差が出る。

| 称号 | 必要石高 |
|------|---------|
| 農民 | 0 |
| 足軽 | 500 |
| 侍 | 1,500 |
| 武将 | 3,500 |
| 大名 | 7,000 |
| 天下人 | 12,000 |

**仲間**
マップ上の民間人に近づくと行列を作って付いてくる。3人以上集まれば右クリックで突撃が使える。商人と足軽は離脱するので、常に補充が必要だ。

**橋ボス**
マップの橋には番人がいる。倒すと先のエリアへ進め、大量石高獲得。

**辻斬り**
QTE。失敗で即死だが大量石高獲得チャンス。栄えているところほどでやすい

**下克上**
城に攻め入り殿様を倒せ！　チャレンジは何回も可能

---

## 敵の種類

- **雑魚敵** — 時間経過で強くなる。序盤に稼げ
- **橋ボス** — 橋を守る番人。倒すと先へ進める
- **辻斬り** — ランダムでカットインしてくる敵。撃退できなければ即死
- **殿様** — 城門に出現。入城後一定時間以内に倒せ
